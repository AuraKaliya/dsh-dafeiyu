# v0.22.0 预览版

2026-10-27。

安装配置新增 `model.auth: "dsh-account"`，可通过官方账号与模型提供器复用当前机器已有的DSH登录，含既有图像内联通路；无需单独提取或复制API Key。默认API Key路线保持兼容。外部来源、其它环境的账号记录与未知记录在调用前拒绝，不静默清除已有登录。

接通DSH桌面已有工具链。启用 `dshTools:true` 后，主人自然提出的任务与有效计划唤醒可使用DSH已安装的工具和技能；目录、参数与运行状态由程序提供。普通群成员不因此取得系统执行权限，独立CLI仍需保持该配置关闭。

QQ一轮可按意思发送多条消息，也可在实际任务进行中发送必要阶段反馈。普通回复、阶段反馈和任务结果共用QQ表达规则；长期表达偏好通过既有Memory与Growth保存和装配，按会话隔离。沿用5秒消息合并、群助手过滤、24小时历史窗口和2—10秒发送延迟。

任务阶段由程序控制，模型负责探索方法、成果的最终评价和表达。正常停止不再直接等同于目标完成；评价缺失或无效时保留原任务等待处理。工具大结果按任务与会话保存，可分页回看，避免为补读重复执行。核验、表达和发送分别保留超时与失败状态，必要失败反馈通过原人格会话整理，不转发被拒的草稿。

插件管理沿用DSH安装器，在当前任务安全交接后执行。程序确认新能力实际加载及原授权仍有效，再恢复原任务；需要重启时等待宿主实际重启。模型可以选择保留有来源的评价作为经验候选，仍需经过原有记忆与成长流程。

## 升级

先停用插件并备份外置实例目录，再安装本版。已有v0.21.0实例继续使用原配置、身份、人格、记忆与会话，无新增数据库升级。更早版本仍需完成原QQ库版本8迁移。不要复制其它机器的凭据、QQ或B站登录态。启用DSH工具链请见[配置说明](configuration.md)。

## 验证范围

在Windows本机完成相关程序与组件检查，并在发布前运行全量回归、分发隐私与隔离安装检查。模型与平台响应使用模拟；实际语义质量、自主更新后的长期效果以及真实QQ/B站完整通信仍需独立验收。具体结果见[验证范围](validation.md)。

# v0.21.0 预览版

2026-10-27。

QQ消息在同一会话、同一发送者最后一条之后等待约5秒再一起理解，持续输入最长15秒。保留每条原消息身份、引用和媒体顺序；重复事件不重置等待，撤回及群助手失权会拦住旧内容。主人明确的任务控制不等待合并窗口。

新增本地表情库。她可以自主挑选已实际读图的QQ表情收录和使用，保存原始GIF等图片，支持配文字或纯表情回复；主人保留列表、通用化、标签、改名、停用和删除入口。自动收藏默认只在来源会话使用，不直接扩大为通用；发送目标和最终内容继续由Core核验。

本版同时包含此前尚未发布的QQ接入更新：

- 原版SnowLuma `send_packet`读取群助手状态，由本插件适配层统一过滤，与现有群列表入口共用同步周期。收进群助手停止自动处理，移出只接收新消息。
- 完整连接图片、语音、文件读取和按需历史浏览。每次观察最多回看此前24小时，可选择感兴趣的历史引用回复，历史不重放成新入站。
- 回复生成完成后按文字量等待2—10秒，非文本量按0计算；保留原发送回执及不明结果不重试保护。

## 升级

现有实例先停用，使用Host迁移流程备份并将QQ库升级到8，再启动。沿用原有外部配置、身份、人格、记忆及会话目录，不重新初始化。表情收录依赖媒体与视觉配置，按[配置说明](configuration.md)启用 `qq.stickers.enabled`。它不要求放开一般语音、文件或任意图片发送。

QQ更新的77项直接相关检查通过，分发包另做打包、隐私和独立安装检查。仍为预览版，没有重跑本版全量回归，也未向真实QQ发送本轮测试消息。详情见[验证范围](validation.md)。
