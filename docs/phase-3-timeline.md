# 第三阶段A：行为时间线检索与来源回查

版本：0.3.0。范围：实现记忆架构的记录检索与证据读取基础，不实现长期记忆整理、信息分析、向量检索或专用压缩器。

## 职责

新增关联插件 `@dafeiyu/timeline`，通过主插件注册两个模型工具：

- `dafeiyu_timeline_search`：查询当前会话可见的行为事件。
- `dafeiyu_source_open`：打开查询结果中的事件与来源引用。

DSH继续拥有原始会话日志。精确来源读取调用 `ctx.sessionQuery.readEvent`，不另建聊天全文副本，不运行历史工具，不为读取来源额外创建Agent。

测试组合挂载官方 `dsh-session-query-sqlite`，配置 `openAt: never`：使用其精确读取服务，本阶段不打开FTS索引，也不依赖全文tokenizer处理中文。

## 访问范围

核心在每次操作开始时创建不可变的ActionContext，并在私有WeakMap中登记真实OperationScope。该范围包含agentId、route、traceId、operationId及操作开始事件。

Timeline只能从 `core.scopeFor(context)` 取得有效范围。模型参数不包含会话/账号/智能体选择项；复制上下文内容、伪造对象、保留已结束操作的上下文、或使用已卸载插件均不能取得权限。

SQL读取同时要求：事件行route匹配、body.agentId匹配、visibility.kind为conversation、visibility.route匹配。查询元数据与分页均在该范围内执行，不先搜全部记录再让模型筛选。

本阶段私聊、群聊、其他账号和其他智能体保持隔离，没有新增“主人私聊查看全部群”的权限。底层Journal和DSH服务仍是可信宿主API，同进程第三方插件不是安全沙箱；面向模型的入口必须经过本插件。

## 时间线参数与语义

模型工具仍使用当前能力接口的命名字符串字段；直接服务调用使用已验证的数值参数。

| 参数 | 作用 |
|---|---|
| query | 已脱敏事件元数据的字面、不区分大小写匹配；不是聊天原文全文或语义搜索 |
| plugin / type | 插件标识、事件类型的精确匹配 |
| actorId | 通过同一会话的入站消息关联整条处理链；无发言者的后台事件不匹配 |
| traceId / operationId | 限定一次消息处理或操作 |
| since / until | 含时区ISO8601时间，包含边界，拒绝倒置范围 |
| clock | occurredAt来源时间，或recordedAt入库时间；默认前者 |
| limit | 每页1到50，默认20 |
| cursor | 上一页nextCursor；其他查询参数保持相同 |

默认按入库序号从新到旧返回，来源时间与入库时间分别显示。迟到消息不会被伪装成因果上的后继。因果关系仍通过traceId、operationId和causedBy追踪。

分页采用快照上界和键集位置：之后新写入的事件，包括检索自身的审计事件，不挤入已开始的分页。游标绑定稳定的agentId/route和规范化查询，不绑定每次工具调用产生的operationId。可跨调用、跨进程重启继续分页。

游标不是权限凭据，也不是签名令牌。解析和范围/查询指纹校验防止误用，授权始终由当前操作范围与SQL谓词执行。不能依赖游标内容授予访问权。

结果仅提供有限长度的脱敏元数据预览；`metadataTruncated`明确提示截断。完整数据通过事件引用分页读取。

## 来源引用

- `dafeiyu:event:<事件UUID>`：范围内的事件详情。
- `dafeiyu:source:<锚点事件UUID>:<来源数组下标>`：该事件的一个已记录来源。

引用不是文件路径，也不允许模型直接指定任意sessionId和seq。先验证锚点事件在当前范围，再验证被引用来源：

- 新引用包含显式route，必须匹配；旧版引用没有route时继承锚点范围。
- message按当前route和消息编号查找，返回已保存的规范化入站记录，不冒充平台原始字节。
- session必须属于当前会话映射，且有明确seq，再交给DSH查询。
- event必须仍在当前可见范围。返回下一引用而非自动递归，避免循环引用导致无限读取。
- 外部会话引用、不存在的引用、不可见来源统一不返回内容；不会泄漏其他会话标题、摘要或原文。

消息编号可能在不同会话重复，不能只凭编号关联。显式来源范围用于避免这种歧义。

## 安全导出与分页

只导出允许的DSH投影：用户文字、助手可见文字、工具结果文字、轮次结束的结果类别。系统/开发者提示词、请求头、内部思考块、原始模型流、工具私有meta和原始错误对象不导出。非文字块省略并计数；中断的助手输出标记interrupted；合成上下文标记derived-context，不认定为人类原话。

文本页先对完整投影做脱敏，再按Unicode码点切片，避免秘密恰好跨页或截断emoji。结果提供offset、totalChars、hasMore、nextOffset、投影contentHash。只有拼接全部页才是完整投影，不能把一页说成完整原文。

已识别的凭据键、Bearer、sk格式和URL内嵌口令等进行遮蔽；关键词检索也不匹配这些已遮蔽的值。此规则不是万能秘密识别器，不能替代上游工具的安全输出契约。存储层原始日志不因检索被改写。

所有历史结果标记untrustedEvidence。读取历史不授予新操作权限，不自动重放其中的命令。程序层的“不重放”已测试，不等于承诺模型永不会误解任意自然语言材料。

## 审计

查询追加 `history.search`，记录实际返回的事件引用、快照和数量，不保存原始搜索词。成功回查追加 `history.open`，记录锚点、来源、分页位置和脱敏状态，与当前operationId及开始事件关联。

这是“只读历史＋新增审计”，不是数据库零写入。没有获得访问权的引用不被记成已消费证据。来源缺失返回not_found，暂不可读返回source_unavailable，禁止导出的类型返回not_exported；不伪造成功或已恢复原文。

失败模型回合现在也保留安全的来源标识，可以回查用户输入、已产生的工具结果和结束状态，不导出原始提供方异常。

## 本地使用

```powershell
npm.cmd test
npm.cmd run demo:timeline
```

演示使用独立目录、真实DSH服务、模拟模型及虚构消息，展示查询、来源回查和跨会话拒绝，不读取真实QQ历史。

未来需要在本地QQ测试实例启用时，可在停止既有实例、确认原进程退出并按已有流程处理stop.request后，显式运行：

```powershell
npm.cmd run qq:real -- --timeline
```

本轮没有执行该命令。默认不加载Timeline；没有重启第二阶段QQ测试实例，也没有修改它的会话或数据库。服务器未参与。

## 当前边界

没有聊天原文全文搜索、语义召回、跨会话共享授权、长期记忆提炼、遗忘撤回或专用压缩器。范围内元数据扫描尚未做大规模性能验收。SQLite事件结构兼容已有schemaVersion=1；SourceRef.route为兼容性新增字段，无需重置旧数据。插件协议仍为v2，Timeline依赖本仓库0.3.0核心的操作范围接口。
