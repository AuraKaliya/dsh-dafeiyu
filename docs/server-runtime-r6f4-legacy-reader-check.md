2026-10-27，北京时间。本步完成 `server-compat` 的读取端及公开类型；没有加载到实际服务器或普通会话，没有迁移/写回旧人格与真实记忆。Core 动作、Memory 来源验证和生产 Host 装配是后续接线。

## 行为

打开既有服务器目录并固定真实 resetAt；缺失不造默认。读取仅针对当前平台、账号、会话和发言用户，以真实 reset/since 限制来源。QQ 与 B站数字账号空间不互通，群/私聊隔离；无来源偏好、summary、基础 Markdown、混合归属记录及固定核心不进入结果。

可读项标记为 `legacy-history-claim`、`adopted:false`、`instructionAuthority:false`，保留旧 ID、来源版本和可审阅文件指纹，不自动当作已采用人格或独立证实的消息。共享事实重新核对当前源候选的 ID/version、可见性、sender/message/time；撤回、私密化、变更或到期后旧 ref 失效。可选程序来源核验端口一旦安装，只接受严格 true；失约返回 undefined 也拒绝。

保留旧 shared fact 的实际 ID，而不重新按 trim 后 section 生成：旧写端曾用 trim 前 section 计算 ID，重算会错误丢掉合法旧记录。归属仍由当前有效 source 完整验证，未降低跨会话隔离。

有界读取核验目录、文件 BigInt 身份、字节与纳秒时间，拒链接/hardlink和读中变更。原文件不改写。记忆使用整文件版本，旁行修改也可能使旧 ref 失效，须重新读取；resetAt 则按语义值投影，正常游标更新不会使全部来源永久撤销。不声称跨文件 OS 事务或能识别任意自然语言私密内容。
