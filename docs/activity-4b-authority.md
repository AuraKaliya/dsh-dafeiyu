# 自主活动4B：核心来源锚点与计划工具

2026-10-25，基线`7b65e10`。

核心新增程序接口：从实际v3写操作捕获活动来源锚点、检查锚点、为真实终态任务生成维护锚点、只建Task而不立即运行，以及持久生命周期订阅。锚点绑定原Run、操作、Task epoch、输入依赖、来源、策略、底色和动作声明指纹，保存于既有run_inputs；公开值只是定位与哈希。发起Run未结束为pending，未知效果／来源或策略变化为stale。维护锚点只承载实际任务整理依据，不能假装新模型输出。

新计划工具在真实原生Task中使用：plan、update、status。模型不能提供producer／policy／owner；兴趣引用须已曝光，实际上下文的其它依赖也进入核心锚点。计划可暂停、改期、取消或更改自己的探索目标；新目标生成新的工作代次，不改原Task。只有owner Task及当前活动工作Task能读取／修改。此步未启动计时器，实际唤醒与本轮改期收尾由4C接入。

明确原生任务与聊天进入优先队列；核心提供前台等待数量。继续运行会沿父链复核原wake授权，不因origin变为continuation而丢掉撤销检查。原有普通Task／wake接口保持兼容。最小唤醒间隔同时约束全局机会，不可通过创建第二个计划绕过。
