# 第三阶段A验收记录

日期：2026-10-23（北京时间）。版本：0.3.0。

结果：行为时间线检索、来源回查和范围隔离已实现；57项自动化测试通过，无失败或跳过。`npm.cmd run demo:timeline`通过，展示检索事件、打开当前会话原文、拒绝其他会话引用。

另以localHost的timeline显式开关完成启动烟测：真实DSH服务＋模拟模型成功挂载channel-simulator与timeline，执行检索并交付结果。核对既有QQ状态文件，进程仍为5940且在线，扩展仍仅qq-acceptance-tools与channel-qq，没有加载新能力。

## 验证范围

测试使用真实DSH Agent、Session、工具运行和SessionQuery服务，模型响应受控。数据为独立临时目录和项目演示目录中的虚构样本，未复制私人记忆、调用真实模型或发送QQ消息。

本阶段新增24项测试，连同此前33项回归测试全部通过，覆盖：

- 查询前限定会话和agentId，拒绝伪造范围。
- 插件、事件类型、发言者、trace、operation及字面元数据筛选。
- 时区等价、时间范围、迟到事件与入库顺序。
- 分页期间新增事件不改变快照；跨实际工具调用与重启继续分页。
- 游标不能在其他范围或查询中复用，关键词不解释SQL通配符。
- 已遮蔽的凭据值不参与关键词命中。
- 模型工具实际返回事件引用与来源内容，读取留下审计引用。
- 私聊引用放进另一个会话无法打开；可见锚点不能夹带外部会话来源。
- 相同消息编号的显式来源范围仍被核验。
- 内部思考、系统提示词和工具私有内容不进入导出投影。
- 读取工具结果不再次执行工具，并遮蔽凭据形状字段。
- Unicode分页与跨页脱敏，返回明确的后续位置。
- DSH surface替换后仍能按原seq读取原文。该用例模拟上下文替换机制，不是完整专用压缩器验收。
- 已结束、伪造或插件卸载后的操作上下文不能继续读取。
- 失败回合保留来源与结果状态。
- 引用在重启后有效，读取不额外创建Agent。
- 文件路径式输入不会退化为任意文件读取。

## 实施中发现并修正

分页指纹最初包含了操作上下文中的临时operationId，导致跨工具调用续页不匹配。现只绑定稳定agentId/route及规范化过滤条件，并有针对性回归测试。

DSH上下文替换测试必须同时记录被替换事件的来源序号。测试已按DSH规则补全sourceEventSeqs；没有绕过DSH校验或修改其主循环。
