# QQ 2C-3：浏览、观察与选择性记忆联合程序检查

日期：2026-10-25；接续 `6020556`。2C-1缓存已提交 `7a7f2bf`，2C-2通用核心／记忆接口已提交 `6020556`。本步完成实际QQ能力、撤回事件、Host装配与配置示例。所有模型输出和平台消息均为虚构夹具；没有连接服务器或真实QQ。

## 实现与边界

QQ保留v2接收／普通回复渠道，另注册v3 `qq-capabilities`。核心验证真实调用上下文与资源范围，记忆插件通过通用观察端口负责持久化、依赖、选择和失效，QQ不直接访问记忆内部库，也不接管模型循环。

| 动作 | 实际行为 | 约束 |
|---|---|---|
| `qq_groups` | 返回当前执行范围内的会话、群名、同步覆盖 | 当前聊天仅当前会话；原生Task取策略resources与平台允许范围交集 |
| `qq_browse` | 读取本账号已收发的最多200条本地文字缓存，返回页面、观察引用、覆盖及下一游标 | 每页最多20条／8000个UTF-16单元；固定水位，长文字按Unicode码点续页；不补离线历史，不理解媒体 |
| `qq_observe_select` | 对实际曝光且仍有效的页面选择none、original、fragment或summary | 程序绑定观察身份与版本；原文／片段从页面取，摘要标为推断且继承实际输入依赖 |

普通群聊天只进入有界缓存，不唤醒模型、不自动成为长期记忆。none只留下选择回执；观察元信息不复制未选正文。DSH工具历史仍由原机制保留，不能把未创建memory item误解成无任何记录。聊天记忆限当前范围；原生Task贡献为task内部／external:none，不自动发QQ。这里没有自主探索调度、人格自动采用、分段发送、新任务桥接或媒体理解。

同一Run中相同browse请求返回同一页面；模型改变查询不能借相同requestId混用。游标与选择票据绑定执行范围、意图版本、账号、会话及本次装载。快照默认1小时／256份，重开、来源变化或过期后重新浏览。限制用于缓存容量和页面大小，没有恢复每轮调用次数上限。

## 撤回与来源连续性

本账号 `group_recall`／`friend_recall` 通知依据 [OneBot 11通知事件](https://github.com/botuniverse/onebot-11/blob/master/event/notice.md) 解析。错账号／未知禁用范围不处理；已知来源在退群后仍可接收迟到撤回。缓存写墓碑，迟到重复消息不能复活。元信息与撤回事实不依赖正文是否仍在200条缓存内。

实际联调暴露了原聊天输入仍能残留的问题，现由Journal记录可查询的撤回事实，memory来源追踪和timeline回查一并拒绝该来源。后续模型上下文不再使用其旧输入及相关派生材料；原始审计和已送达内容不抹除，也不声称撤销已经完成的外部发送。重复通知保持一条审计，若中断发生在缓存墓碑之后、审计之前，重复通知可补齐审计。离线未收到的事件仍是明确缺口。

来源指纹按会话计算，另一群的缓存变化不使本群来源失效；原生Task重新核对资源提供方。群资格变化／插件卸载使相应来源不可用。摘要历史无法核验时拒绝写入或暂不返回，不能编造完整追踪证明。

## 装配、兼容与数据

- `capabilities.enabled`默认false；启用需要managed生命周期、memory观察服务、执行资源授权、来源追踪和conversation策略中的三个动作／本地写权限。Host在连接前校验这些依赖。
- `memory.sourceTracking:true`只追踪来源，不自动压缩或增加辅助模型调用；已有compaction也提供追踪。Host状态暴露sourceTracking和QQ能力是否注册，能力清单包含活跃v3扩展提供的feature。旧状态快照缺少新增状态字段仍能读取。
- 一次性run不启动QQ；未装配的可选QQ或single-run渠道的专属策略不阻断无关原生任务。原生任务自身要求不可用QQ动作时仍拒绝，不能虚报可用。
- 开启能力后，新缓存键包含账号；旧未绑定账号缓存原样保留，不自动混入页面或引用正文。既有核心入站去重防止切换命名空间后重跑同一消息。旧发送恢复只在核心已有同账号入站见证、且新命名空间没有该来源事实时回退查询旧引用ID，不恢复旧正文。
- 本步无新schema迁移。目标仍为QQ v3、memory v9、journal v2、runtime v2。旧QQ／memory数据沿已提交的显式备份迁移流程升级，不能以init重建或用旧程序写新库。

配置示例已更新为 [host.qq.example.json](../profiles/host.qq.example.json)，包含虚构ID／脚本模型。没有启动此配置连接真实平台。使用与迁移说明见 [统一入口](host-usage.md)。
