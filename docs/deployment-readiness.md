# 部署检查入口

当前指南为 [全新 DSH 安装指南](../packages/plugin/docs/install.md)。本文件不保存某台机器的固定路径或旧测试数量。

部署检查分三层：

1. 安装：包名称、版本、修订、运行代码和客户端、独立依赖、profile 声明/锁/实际解析、无 BOM 配置。
2. 实例：配置检查、初始化身份一致性、库版本、占用、冷启动、重复启动、停止及重启。
3. 真实能力：模型、QQ、B站和媒体分别验证，只记录实际发生的请求与结果。

scripts/verify-local-deploy.mjs 是只读检查器；静态检查通过不证明实例在线。上线验收还须确认实际管理回执、当前进程及状态时效。数据升级须先停机、备份并显式迁移。

历史记录位于 docs/checks/ 和 docs/results/，用于追溯，不作为当前安装指令。
