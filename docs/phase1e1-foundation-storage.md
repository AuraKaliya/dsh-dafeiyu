# 第一阶段1E-1：底色、人格契约与增量存储

日期：2026-10-24（北京时间）。接续1D提交`2ec6ec1`，依据人格成长方案1.0及第一阶段方案1.1。

## 实现

- 新建[身份与初始底色](../profiles/persona.foundation.md)，仅包含已确定的身份、爱世界、好奇、独立判断、事实诚实、任务责任与能力边界；没有引入旧人格、私人经历、固定爱好或口头禅。
- 底色读取采用严格UTF-8解码，拒绝空文件、NUL、不合法编码、非普通文件和超长内容；固定正文哈希与文件身份哈希。一次读取的快照不可变，后续文件变化不会原地改变旧快照。
- contracts增加有版本的人格来源、候选、阶段状态、业务动机、连续性检查点、任务意图事件及Run人格清单Schema；具体行为服务在下一子步骤接入。
- memory新增v7→v8迁移：候选及修订、阶段及修订、依赖索引、幂等请求／outbox、连续性检查点与任务意图事件；旧v7建表语义、正文、边界和哈希不重写。旧辅助迁移只扩展已完成版本识别到v8。
- runtime新增v1→v2显式迁移与不可变`run_persona_manifests`。旧Run仍为legacy-unbound，不补造采用证明；managed核心的新Run与人格清单在同一开始事务绑定。
- 当前阶段提供者尚未接入时清单明确`stageStatus=not-configured`，不冒充已经存在空人格服务。候选／阶段行为与合法投影在1E-2实现。

Host迁移检查器支持memory v8／runtime v2，新迁移计划绑定实际代码指纹（含core迁移辅助文件）。已有v1 runtime直接启动会要求显式迁移，不通过create参数偷偷升级。这里只准备Host存储工具，正式日常启动仍属1F。
