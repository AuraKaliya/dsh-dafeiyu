# M5C：多代摘要与精细来源依赖开发方案

日期：2026-10-24。承接M5B，继续本机开发；服务器、真实QQ和模型绑定配置不修改。C1、C2、C3-A及C3-B的限定条件校验、组内受控融合与有效原文重建已实现。具体见[C3开发方案](memory-phase-5c3-plan.md)、[C3-A验收](memory-phase-5c3a.md)与[C3-B验收](memory-phase-5c3b.md)。

## 目标与不可放宽的约束

会话状态变化只触发复查，具体来源决定失效范围。原文、逻辑删除状态和历史版本保留；不通过覆盖原文或物理删除实现退出。每个片段保持会话隔离、原始来源与版本，不允许跨会话凭引用读取。

必须区分模型声明的支持引用与程序记录的生成输入依赖。模型看过A和B，即使只声称引用B，生成结果仍继承A、B。要缩小依赖，应重新隔离输入生成新片段，不能删依赖字段而沿用旧正文。

一条记忆变化不应清空无关历史。但混合回答、同一原文消息中的不可拆分内容、未适配工具的未知来源，可以按确实无法分开的最小单元保守处理。不能把语义上“看起来无关”当作已经证明没有依赖。

C1并不把同一回答或同一摘要内部的句子自动判定成独立事实。一个摘要仍是一个替换单元，但其状态由实际来源决定，不再直接继承整个会话的状态代号。

C2的新检查点按隔离输入组生成信息片段，并将完整证明移出主模型视图。同一组中的片段仍继承完整组依赖，不能仅凭语义分句缩小依赖。旧v1/v2摘要不自动猜测分片。

## 来源模型与版本

来源包含原始消息、长期记忆、工作条目、工具反馈、关联插件条目和旧版保守依赖。所有依赖带agent与会话范围，内容使用不可变引用及哈希，状态版本单独校验。

原始消息身份是会话内消息标识，不是内容哈希。同文、同发言者、同时间的不同消息仍是独立来源；不同时间线引用指向同一消息则必须视为同源，不能绕过删除。

长期记忆固定内容revision、状态version、哈希及祖先状态。工作区整体版本用于并发写入，条目版本只在该条目内容、任务、来源变化或删除后重新加入时改变。取消检索选择只改变装配，不等于原记忆失效。

片段模型保留不可变正文、任务、内容/来源版本、直接父片段、原始来源闭包、策略与生成方式；C3-A已实现多代证明与展示状态分离，有效时间的语义提取留待C3-B。替代关系与生成依赖分开：后续新片段可以替代失效片段，但不能因此被认作读取了失效正文。

## 多代合并规则（C2/C3）

组合展示只排序、聚合独立片段；子片段分别失效。语义融合产生一个新片段，继承全部实际输入的依赖并集。默认优先组合展示，不为了压缩率把无关主题绑成共同失效单元。

每代同时保存直接父片段和原始来源闭包，由代码沿图计算；不能只剩“摘要引用摘要”。完整依赖留在持久记录中，上下文仅装配必要正文和引用。父子边不得回指未来或形成环；超过依赖容量时停止合并或重新分片，不截断闭包。

跨任务、跨可见范围、混淆时间有效性、有未解决矛盾、或合并收益不足时不融合。保留否定、条件、不确定性、失败状态、准确标识和最新更正。高代摘要不自动获得更高可信度。

## 删除、修订与恢复

变更先定位直接依赖，再传播到后续派生节点。失效只修改活动视图与派生状态，原文保留。混合片段依赖A、B时，删除A需要撤下该片段；用B重建时不能把旧混合正文作为提示词要求模型自行删A。

来源恢复后状态版本继续增长，旧依赖不能自动生效。已知原文引用、工作选择、反馈档案和助手转述都要检查各自保存的状态。显式历史/删除回查只供当轮使用，不能经后续摘要或候选流程自动恢复。

生成前、提交前、请求准入、输出过程中及来源回查时验证。无关来源变化可继续；实际输入变化则拒绝旧结果。普通失败保留有效旧视图，删除导致的失效内容即使重建失败也不能重新装配。

## DSH与存储分工

DSH继续负责模型循环、追加日志、surface替换、工具配对、检查点及恢复；主插件控制所有权和装配；记忆插件解析并校验权威来源。

C1来源记录、C2完整证明和局部视图均使用DSH插件记录接口，索引可从日志重建。记忆和反馈的SQLite状态仍是删除与版本的依据，缓存只加速查询。本轮先使用会话内缓存；持久SQLite查询投影按后续规模验证决定，不增加第二份事实历史或独立图数据库。

保留2GB应用预算思路：小批次、有限验证缓存、依赖数量上限；超限失败不能丢依赖。长期会话的日志增长、索引和模型摘要开销需要另做资源验收，不以本机短样本推断服务器容量。

## 迁移与验收

M5B v1摘要保持保守状态代号校验，失效仅退出这些旧单元。不能从模型猜测恢复精细依赖。缺少历史来源状态证明的旧工作选择/反馈，不回填为“当时有效”；需显式刷新选择或进行受限历史回查。更早没有归属清单的原始会话，不自动伪装成精细来源，需单独迁移核验。

C1验收要求：A变化时无关B的消息标识、正文和摘要保持；混合输入继承完整依赖；相同文字不同来源不误伤；同源不同引用不能绕过删除；删除再恢复、父记忆恢复、重启、并发变化和跨会话读取均正确。

C2新增同一摘要包内的片段级替换与预算测试；C3新增至少三代派生、混合融合、原文重建、循环/遗漏依赖拒绝、故障恢复和真实模型保真测试。C1脚本模型验收不能替代这些后续验收。
