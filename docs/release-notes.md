# v0.21.0 预览版

2026-10-27。

QQ消息在同一会话、同一发送者最后一条之后等待约5秒再一起理解，持续输入最长15秒。保留每条原消息身份、引用和媒体顺序；重复事件不重置等待，撤回及群助手失权会拦住旧内容。主人明确的任务控制不等待合并窗口。

新增本地表情库。她可以自主挑选已实际读图的QQ表情收录和使用，保存原始GIF等图片，支持配文字或纯表情回复；主人保留列表、通用化、标签、改名、停用和删除入口。自动收藏默认只在来源会话使用，不直接扩大为通用；发送目标和最终内容继续由Core核验。

本版同时包含此前尚未发布的QQ接入更新：

- 原版SnowLuma `send_packet`读取群助手状态，由本插件适配层统一过滤，与现有群列表入口共用同步周期。收进群助手停止自动处理，移出只接收新消息。
- 完整连接图片、语音、文件读取和按需历史浏览。每次观察最多回看此前24小时，可选择感兴趣的历史引用回复，历史不重放成新入站。
- 回复生成完成后按文字量等待2—10秒，非文本量按0计算；保留原发送回执及不明结果不重试保护。

## 升级

现有实例先停用，使用Host迁移流程备份并将QQ库升级到8，再启动。沿用原有外部配置、身份、人格、记忆及会话目录，不重新初始化。表情收录依赖媒体与视觉配置，按[配置说明](configuration.md)启用 `qq.stickers.enabled`。它不要求放开一般语音、文件或任意图片发送。

## 验证范围

QQ更新的77项直接相关检查通过，分发包另做打包、隐私和独立安装检查。仍为预览版，没有重跑本版全量回归，也未向真实QQ发送本轮测试消息。详情见[验证范围](validation.md)。
