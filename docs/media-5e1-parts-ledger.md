# 统一媒体5E-1：回复媒体协议与逐部件账本

2026-10-25；细则基线`c2ef104`。

新增ReplyMediaManifest和image／record／file部件契约。清单固定replyId、实际目标、原消息、Run／任务锚点、最终正文hash、草案版本、部件身份／hash及材料stamp。首版每部件至多16 MiB，整份媒体清单至多32 MiB、8个媒体部件；正文继续原4000 UTF-16单元分段并完整还原，顺序为正文后接所选媒体。文件名不含路径或控制字符。

QQ v2媒体交付账本使用v5预留表，旧v1文字账本不改含义。每部件单独pending／sending／sent／unknown，确认全部部件才写整份回执。发送中断恢复成unknown，不能重发该部件或越过它发送后续部件。确定尚未发送的准备失败保留原计划。v1／v2不能共用同一replyId，旧文字回执不能被当成追加媒体的许可。

持久化计划还会从清单及完整正文重新推导，不只比较缓存的plan_hash；即使某处同时误写计划和其hash，也不能使部件偏离已固定清单。完整性hash本身不是授权：5E-2仍须接核心真实授权和权威清单查验，5E-4才接实际传输。
