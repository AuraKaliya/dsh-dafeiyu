# 统一媒体5A：契约、作用域和资产存储

2026-10-25；方案基线`1b022ae`。

新增MediaSource／MediaAsset／Coverage及程序provider／MediaPort契约。源引用代表可解析对象，资产ready只代表核验后的字节存在，默认没有处理区间、没有模型曝光，也不意味着理解。模型接口不包含任意路径、URL、请求头或授权身份。

核心提供实际v3上下文与来源证明的媒体访问入口：核验动作所有者、真实资源场景、provider当前证明和调用生命周期。复制上下文、换场景、篡改来源或调用结束后复用均被拒。服务的字节broker与解码实现继续在5B接入，5A没有声称已能看图或听音。

独立media v1库保存身份、源／资产不可变修订、blob元数据、请求、租约、作业、曝光和审计。source与Task epoch变化使旧资产引用失效；删除后恢复不复活旧引用。失败事务不留下ready资产；重启把未完成作业和半资产标成中断／失败，不补造观察。

缓存回收采用先持久撤销可读状态、再物理删除并确认的顺序；删除失败继续计入配额并保留清理待办，不能假装释放空间。活跃租约保护数据。可用性与内容／撤销版本分开，缓存回收不把历史“当时看过”的证据改成用户删除；被回收的旧票据仍不能直接读字节，重新取得产生新资产。
