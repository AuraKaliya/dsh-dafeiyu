## 2. 责任与依赖

大肥鱼决定保留、分析、采用和探索方向。记忆负责候选的分析、来源与范围校验、版本和请求持久化；核心负责真实执行身份、任务目标／epoch、事件与运行权限；自主活动负责安排时间和条件。QQ等插件只提供已发生的操作与观察，不自行改阶段人格。

依赖顺序为核心注册→时间线／记忆恢复→核心执行配置与事件恢复→服务激活。记忆E依赖Task仓储、原生执行和来源跟踪；不依赖QQ、B站或activity存在。不引入模型循环或第二套聊天历史，辅助分析继续用独立DSH会话，禁用工具和继承提示，只保留可见结果。

无activity时任务事件仍可生成`waiting-scheduler`请求，状态如实显示；大肥鱼可在已有获准任务中按需处理。下一阶段由activity通过既有wake接口建立同一任务范围的maintenance动机Run，或对明确授权的任务范围安排整理。请求ID／任务ID不是访问授权，任何工具读取仍需核心签发的实际上下文。

## 3. 对象与不变量

### 3.1 经历与经验

Experience含稳定ID、版本、agent/task/epoch/Run、目标快照、原始动机、程序记录的操作结果、来源引用、覆盖及缺口、分析结论和适用条件。严格区分：程序事实、来源中的主张、模型推断、自述。Run完成仅表示模型运行结束，操作的failed／partial／unknown不能归为任务成功。

经验版本包含当时目标、观察、行动、实际结果、解释、适用条件、反例／未知及修订原因。新经验先为候选；大肥鱼可持版本和理由复核为held／accepted／rejected／withdrawn。accepted只是“采用这条有条件的经验”，不提升为世界真理或底色。修订追加新版本并保留旧版本，不修改旧正文；expectedVersion防止丢失并发修订。改目标产生新epoch后，旧经验不得凭旧授权自动进入新任务。

派生记录继承整个实际分析输入及调用者已曝光上下文限制，不能只记录最后引用的支持。内容保持task内部；跨任务／场景复用必须走既有选材与独立授权，不增加“全局经验”绕行通道。来源删除、更正、范围收紧立即使相关记录不可用；恢复也不复活旧来源版本。

### 3.2 关系

首版支持：属于任务、支持、反证、修正／替代、同一已核验实体、兴趣相关。程序记录的Task归属和Run关联由真实执行身份生成。其余分析关系保存为候选，绑定精确来源／经验版本和理由。模型不能以名字相同或相邻时间证明同一实体或因果；没有受信身份依据的same-entity保持held。自环、指向不存在或越界对象、无来源关系拒绝。修正链不删除反证，不允许循环替代。

同一根来源的摘要、转述、反思合并为一个根集合，不使用候选的自评分作概率或投票。外部数据中的指令不能改变关系政策、工具权限或底色。

### 3.3 整理请求与水位

MaintenanceRequest保存固定ID、去重键、范围、taskEpoch、原因、原始事件ID／Run、输入引用与水位、发生／登记时间、版本、状态、结果ID和稳定错误。事件接收成功前必须持久化。相同事件重复投递返回原请求；相同ID不同正文报冲突。已处理水位只在成功提交后推进，失败不跳过材料。

状态：waiting-scheduler／ready／running／completed／failed／cancelled／stale。没有调度器不是失败；正在分析时关闭则中止，恢复留下明确失败或可重新申请状态，不能无声重复模型调用。请求过期、目标epoch变化或来源失效，禁止旧结果提交。重试由新的显式请求／新安排触发，保留前次记录。提交结果与请求终态、审计outbox在同一SQLite事务；提交后丢确认以固定请求查回原结果。

## 4. 接口

| 接口／工具 | 调用者与内容 | 边界 |
|---|---|---|
| `ExecutionMemoryPort.recordLifecycle`（可选扩展） | core在持久outbox确认前传入固定事件、Run/Task/epoch、原始动机、目标和操作回执摘要 | 程序专用，不接受模型伪造事件；老实现可不提供 |
| `assessMaintenance` | 记忆轻量识别任务开始／恢复、完成、等待、失败与新证据；返回原因和水位 | 不调用模型；派生maintenance运行不再触发同类整理 |
| `requestMaintenance` | 受信程序或当前获准任务动作提交固定范围和已曝光来源 | 请求不是能力令牌，不复制无关历史或未选择正文 |
| `dafeiyu_memory_maintenance_status` | 当前task范围内列出有界状态／计数 | 默认元数据，不能全库扫描出其它任务正文 |
| `dafeiyu_memory_consolidate` | 当前任务内执行固定请求：捕获输入→独立分析→复核→事务提交 | 时间／输入／输出预算、取消、来源与epoch复验；空证据可保留程序活动事实，但不能伪造偏好 |
| `dafeiyu_experience_read/review` | 当前task按ID读有效经验、持版本复核或修订候选 | 已失效正文不返回；历史只在同范围明确请求并标明不可再用 |
| 人格候选桥接 | 大肥鱼从有效分析条目选择提出persona候选 | 继续使用PersonaStore；不自动trial/publish，不改固定底色 |
| 后续activity适配口 | 获取待安排请求的元数据／确认安排，核心核验后运行 | 不由memory内部计时器调用模型，不自动扩大资源白名单 |

具体类型在contracts声明，数据解析使用严格schema。模型工具不接受agentId、producer、scopeKey等授权字段。失败码区分SOURCE_STALE、VERSION_CONFLICT、TASK_NOT_ACTIVE、INVALID_RESULT、INPUT_TOO_LARGE、ANALYSIS_TIMEOUT、CANCELLED、IDEMPOTENCY_CONFLICT、DEPENDENCY_UNAVAILABLE；不能把可能已提交写成无副作用。

## 5. 分析与污染防护

输入使用固定sourceId、来源版本、真实文本（仅已保留／可授权取得部分）、来源性质、根谱系及原始任务动机；另外提供已核验的程序活动摘要与当前待比较经验。保留分析路由、策略版本和输入hash。总输入默认64 KiB、输出32 KiB、单次分析120秒；配置可在明确范围内调整。没有工具调用次数限制。超过预算拒绝并提示缩小范围，不截断成“完整”。

输出严格结构化：经历摘要、经验候选、精确支持／反证原文定位、适用条件、未知、关系建议、人格建议。不允许模型提供自由来源ID、篡改程序结果或填高分绕过检查。精确摘录、存在性、范围、根谱系、版本及结构由程序检查；无法完全机械判定的概括保持inference／held，不声称解决语义幻觉。

经验修订同时携带旧版本和新证据，保留旧支持／反证关系；没有新依据不能用相同摘要反复制造独立经历。人格建议仅形成待选择候选；explicit-task/mixed/unknown动机不能仅凭任务接触转成兴趣或稳定偏好。maintenance Run沿用被整理经历的原始动机，不将维护动作误认成自主兴趣。

先分析，后提交；提交前再次校验所有固定来源、历史依赖、任务epoch和目标经验版本。来源变化时整批不提交，保留脱敏失败状态。分析结果不能外发，原生任务结果仍走QQ阶段已经实现的目标材料、人格表达与逐段来源验证。

## 6. 事件、恢复及下一阶段接入

核心只把已持久发生的事件交给记忆。任务开始／恢复仅建立可整理水位；结束／等待／失败／新证据按类型记录需求，可按相同任务和水位合并调度，但原始事件不能丢失。异常和未知效果必须进入经历缺口。

outbox在记忆事务之后确认；崩溃在两者之间会重投同一事件，不重复请求或经验。不扫描旧历史补造本版本前未记录的成长；迁移后从新事件起工作。关闭先停止接收／安排，再取消或等候正在进行的分析，最后关闭数据库。事件的causedBy与originKind保留；整理产生的记录不循环触发自己。

下一阶段activity按此队列持久安排：waiting-scheduler→安排回执→到期wake→核心真实Run→调用consolidate→完成事件回执。计划取消／改期使旧机会失效；调度状态不取代记忆内容状态。此阶段不宣称已有后台自主活动。

## 7. 数据迁移与兼容

memory v10→v11增量追加经历主表／不可变修订、关系、整理请求／事件／幂等回执与审计。不重写已有memory正文、人格、任务、来源或表达包；不把旧数据自动分类为真实成长。新表使用agent+scope索引和限量分页，禁止无界加载正文。现有v2分析及动作不改变含义。

Host迁移目标与只读检查同步为v11，旧profile必须经既有计划／备份／校验迁移，不用init重建。runtime无需为可选事件端口升schema；新增接口只影响装配。新二进制拒绝未知schema，旧二进制不得打开v11库。迁移失败事务回滚；回退需要停机后使用迁移前完整备份，不能覆盖后来增长的数据。

测试旧库用虚构v10样本，检查旧行及哈希、墓碑、人格、任务、表达记录、迁移重入和失败回滚。固定保存的正式验收材料不属于测试临时目录。

每个子步骤单独保存检查记录及机器可读结果，再提交Git；发生失败先记录原因和修复后的定向复测，不能只报最后通过。测试只覆盖改动及其直接依赖。涉及迁移／旧入口时运行对应兼容测试，不以此借口每步跑全量。

本轮测试使用虚构样本和脚本模型，但SQLite、DSH、Host生命周期与回环传输为实际本地代码。模拟分析通过不能说明真实模型的归纳、反证识别和人格质量通过；真实平台、长期成长、162次1G、全量发布回归和服务器部署均另行记录为未执行。
