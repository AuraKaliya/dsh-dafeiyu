## 完成内容

- 读取并冻结HostConfig v1、生效插件配置、模型路由、底色哈希和真实路径；配置相对配置文件解析。
- 允许插件清单覆盖现有timeline、memory、QQ、模拟渠道及DeepSeek／脚本模型；复用插件自身Schema，拒绝任意模块导入、明文凭据、agent／dataDir／lifecycle覆盖、配置冲突和依赖循环。脚本模型仅允许test profile。
- 只读预检检查schema、完整性、profile／agent、基础依赖包版本、目录占用、初始化及迁移证明；缺失权威数据库明确拒绝，不在检查中创建空库。
- 新目录初始化复用现有Journal、Run、Delivery、Memory、Analysis、Working、Feedback及QQ存储实现。只有明确的新空目录可初始化，不复制或修改底色，不创建候选或真实经历。
- `host-profile.json`保存版本化路径／身份和初始化状态；失败保留可诊断状态，不删除用户目录来重新开始。
- 本机协调记录位于当前系统用户的`.dafeiyu/host-coordination.sqlite`，与业务数据分开。事务核验PID、nonce和资源真实路径，拒绝别名、共享目录及祖先目录重叠。确认进程已退出后可回收其占用；PID仍存活或状态不明时拒绝接管。测试使用独立协调文件，不修改日常用户的协调记录。

该协调范围是同一系统用户启动的Host；跨用户／服务器服务账户切换仍须部署阶段单独验收，并继续受到核心数据库既有占用检查约束。当前没有常驻Host、真实QQ连接或正式CLI；这些属于1F-2／1F-3。
