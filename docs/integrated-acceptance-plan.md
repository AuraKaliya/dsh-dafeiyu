1. 本轮清理：相关检查通过后提交，整理保留功能和待验项目。

3. 本机7C：核对仍有效的授权、账本、时钟；重新校准，再按原162项顺序执行和记录。
4. 本机7D：QQ私聊/群聊/分段/图片/语音/文件；B站公开浏览、真实音画和固定主人私信；管理员执行、人格化交付及取消/未知。真实写入仅限明确授权的本机测试文件/会话。

当前代理作AI语义复核时标注AI身份，不能填成humanAccepted。以冻结的关键事实、禁止项及实际运行证据逐项判断；不能用模型“我完成了”的自评分代替。需要真人判断的音画真值或主观体验保持独立待评状态，不捏造已评。

## 4. 关键联合流程

- QQ指示/聊天兴趣/无聊天自主唤醒三条路径，都进入Core的真实Task与动机；兴趣不能伪装主人授权。
- 观察→可见来源→选择保存/摘要→经历关联与经验修订→人格候选→试行→结果→复核采用，不能跳步。
- 画面独有信息、音轨独有信息、非语言关键声音及矛盾字幕分别验证。字幕读到不等于看过画面或听懂音频，缺处理器必须明确缺口。
- B站搜索词来自当前允许的公开/任务来源，分页与时间范围可追踪；412/429退避，不反复撞接口。公开评论和弹幕发布不在新能力中。
- 固定主人私信与公开浏览分离，账号/对象正确；大整数ID、起点前消息忽略、发送未知不重试、重启不再生成同一回复。
- 管理员执行使用本机官方headless和真实Windows权限；结果回原会话人格整理。没有整进程树沙箱/业务回滚证明时保留unknown，不夸大隔离能力。
- 本项目自己的schema迁移/备份/恢复继续检查；不引入旧服务器history/Markdown人格迁移。

权限越界、来源撤回无效、记忆删除复活、重复发送、私有内容泄漏、伪称完成及模态缺失属于阻断项，不能被平均分抵消。关键事实保留率等原冻结要求继续有效。
