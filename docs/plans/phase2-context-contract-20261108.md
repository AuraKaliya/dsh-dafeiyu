# 第 2 轮上下文治理与离线比较契约

日期：2026-11-08。变更前基线：0.28.9 / API 9，修订 `3d04ae4`；本批实现为 0.28.10 / API 10 / runtime v7。本批不调用付费模型，不向真实平台发送，不部署。

## 比较先于实现

固定样本为同一主人任务顺序读取 12 份 6,000 字符材料，再从第一份归档续读最后 2,000 字符，最终报告送达。每份材料前 4,000 字符在第一次返回时实际暴露；剩余部分明确标为未读。任务保留否定约束、纠正和待办。相同脚本决策、读取次数、覆盖、最终正文及送达要求用于变更前后，不通过少做业务获得下降。

记录每个 SDK 请求的输入 UTF-8 字节、峰值、工具正文出现次数、请求数、原工具调用和归档回查次数。固定断言是已读大正文重复输入减少、总输入下降且业务证据不退化；不预设供应商 token 或费用节省比例。baseline 在实现变更前产生并纳入测试夹具，后续不重写基线使测试通过。

另用同一归档核对单页与批量读回的完整内容、范围、错误和执行回执；记录冷读与重复分页的文件解析次数。时间指标只报告，不用易抖动的机器耗时替代内容与读取次数断言。

## 确定性正文折叠

正文折叠独立于语义压缩开关及容量压力。只处理原任务中已经进入模型请求、来源仍有效、有可靠归档及合法回查入口的工具结果；保留最近两份工具结果，较早结果在净减少至少 512 字节时折叠。未暴露、没有归档、效果未知、失败或多模态结果保持原状；原文与操作账本不删除。

本批可自动折叠的范围是有 DSH 归档证明的工具页，包括批量回查页。观察引用可能只包含元数据，不能用它证明正文可回查；其它没有明确正文回查能力的工具结果保持原文。折叠入口使用实际 `dsh_result_read` 参数，来源有效性同时检查原归档。处理失败和待执行交接保留原状。

折叠保留操作状态、效果、完整性、来源、回执、原始覆盖及可识别的执行失败信息；折叠记录不能把部分读取变成已全部读取。来源撤销、过期、目标变更和取消继续作用于正文、引用及派生回答。替换使用既有 SDK 历史投影、来源继承与持久化，不重执行原工具。

当前目标、最新纠正、禁止事项、工作记录、待办和阶段工具不做语义改写。百万上下文配置保持 `contextCapacity.maxTokens = 1000000`，不新增业务总 token 或总步骤上限。语义整理保持原配置，本批不自动启用。

## 查询与测量

诊断说明要求先用目录、文件定位和搜索确定相关范围，再按宿主实际参数读取正文；目录和路径不是正文证据。增加对同 Task、同来源已归档结果的有界批量回查，每页保持自己的范围、错误和原执行回执，不借批量回查取得 shell 或写权限，也不重新调用原宿主工具。

重复分页可复用已校验的不可变解析结果。缓存有字节和条数界限；文件身份或内容状态变更时必须失效，不能让缓存绕过任务、会话及完整性检查。保存 JSON 采用无 BOM 和原子发布。

每个模型请求的上下文测量关联到该请求 ID，字节和估计与供应商用量分开。已有输入、缓存读写、输出、重试和核验计量保留，未知不算零。软预警只提示大输入（单次输入超过 512 KiB）或相同输入累计至少三次，不停止任务。离线记录明确标注测试来源；未经真实费用验证，只认定输入组织和重复读取改善。

账本测量位置固定为 `sdk-pre-adapter`。SDK 随后的工具声明、文件和媒体投影可能改变适配器输入，不能直接把两处字节作相等断言。比较样本另保留适配器观察值；审计把适配前输入的摘要、字节和会话逐请求核对到测量账本，再用同一适配器位置的变更前后数字判断输入减少。

runtime v7 新增不可变的 `model_request_inputs` 表，以请求 ID 外键关联字节测量、摘要和环境标签，不存提示词正文。显式迁移保留旧请求与结算、核对备份；旧请求缺少输入测量时显示未测量和历史未分类，不补造零值。回退使用匹配程序与完整旧库备份。

完成构建、相关定向回归、`npm test`、保留原 15 场景并加入上下文比较的 16 场景离线审计。接口与发布版本同步修改提供方、调用方、管理界面及测试，完成冒烟和独立发布包初始化。第 2 轮真实成本及模型决策不确定项保持未验，不用本次离线数字代替供应商费用。
