# 第 4 轮本地候选整合与封存

日期：2026-11-08。承接 0.28.12；本轮沿用不启动付费测试、真实外发或部署的限制。前置真实语义、实际成本及平台复验未完成，因此只形成可审阅的本地候选，不标为正式发布验收通过。

候选版本为 0.28.13，API 维持 10；runtime v7、QQ v8、B站 v6、Activity/Media v4、Memory v2 均不变。主要改动位于发布、回归及封存工具和当前文档，不新增业务接口或数据库结构。

## 本轮工作

| 项目 | 本地交付 | 判据 |
| --- | --- | --- |
| R4.1 | 版本、构建产物与验收工具整合；回归报告绑定实际源码/驱动/运行代码摘要 | 全量及冒烟通过，执行期间内容未变，所选测试集不能冒充完整回归 |
| R4.2 | 新目录候选包、自有依赖、新装及重复启动检查 | 包内容摘要正确，依赖解析在包内；重复初始化身份稳定；重复 CLI 启动被占用保护拒绝且原 PID/实例不变 |
| R4.3 | 真实旧发布程序生成合成数据，显式迁移及匹配旧程序回退演练 | 身份、任务、计划版本/水位、批准但未交付正文、未知分段、历史和操作回执保留；备份逐表验证，升级后数据另存，旧程序拒绝不兼容新库 |
| R4.4 | 保存尚未执行的真实观察要求和配置模板 | 不运行计时，不用隔离样本或历史两小时补足；程序、实际模型/配置、场景及判据正式冻结仍须届时核对 |
| R4.5 | 候选封存清单和本地审计，关联全部证据 | 修改包、依赖或证据后核验失败；明确 localReady 与 releaseAccepted 不同，真实语义/费用/两小时保持未执行 |

新增工具先有正反例，再跑候选回归。包检查同时校验实际文件与声明摘要，不能只扫描隐私模式。封存放在发布目录之外，依赖安装在封存之前；包根目录、依赖锁、实际模块解析和证据文件都有内容标识。

迁移演练只使用新建合成目录，不读取正式配置或凭据，不调整任何用户数据库版本。已保留的旧发布包作为匹配的旧程序来源；实际库由其公开存储 API 创建，迁移走当前显式迁移器，不通过改版本号构造升级成功。

本地候选完成后保留清晰的待办：真实模型语义复验、实际模型/配置冻结、费用归属验证、同一进程不少于两小时且有后段业务的观察。只有这些证据和后续部署授权齐备，才能继续正式发布流程。
