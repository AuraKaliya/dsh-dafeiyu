# 第 3 轮组合恢复与本地语义校准契约

日期：2026-11-08。基线：0.28.11 / API 10 / runtime v7。只开展本地程序与 SDK 隔离工作，不调用付费模型、真实平台或部署。

实施版本：0.28.12；共享 API 和数据库结构版本不变。QQ 观察证明升级为提供方内部 v2，绑定群授权代次；群媒体的来源正文同样绑定代次，重新取得绑定会产生不同版本。旧数据保留，不把当前代次回填到历史资料。无法证明原代次的旧群引用不得直接续发，需在当前授权下重新取得来源。

## 固定组合

| 场景 | 触发顺序 | 必须保持 |
| --- | --- | --- |
| C1 交付全链恢复 | 群资料读完 → 生成服务失败 → 重启/受理恢复 → 核验服务失败 → 原稿核验拒绝 → 复用证据修稿 → 首段确认/后段中断 → 重启/续发 | 同 Task/Run/交付，业务只读一次，未批准稿不外发，三稿计数和原回执保留，确认后不重发 |
| C2 未知发送 | C1 到发送阶段 → 后段回执未知 → 重启及重复恢复请求 | 已确认保留，未知不改为未发，不重新调用模型或重发未知段 |
| C3 主人取消 | 首段确认 → 原渠道收到真实主人取消消息 → 交付让出队列 → 控制生效 → 重启/旧恢复请求 | 无死锁；旧第二段不发；任务版本更新，旧通知和旧恢复失效 |
| C4 新意图 | 首段确认 → 主人修订目标 → 同 Task 新代次执行 → 重启/旧恢复请求 | 新结果与旧部分结果分开；旧正文不能借新意图授权续发 |
| C5–C9 撤权窗口 | 查询后、生成恢复前、核验结果后、首段发送前、首段确认后分别撤销群来源 | 仍可保存审计事实；旧原文、派生结果及发送不能越过当前权限；重新加入群不自动复活旧代次材料 |
| C10 媒体来源撤销 | 冻结文件/首段确认 → 停机 → 来源撤销 → 恢复 | 已确认部分不重发，不重取文件，不用旧导出绕过来源；未知状态保留 |
| C11 探测不等于业务恢复 | 业务读取后模型失败 → 轻探测成功 → 重任务再失败 → 新暂停代次 → 明确恢复后原进度续办 | 探测成功只证明该次请求；未完成业务仍阻塞，不重复下载或用成功探测伪装交付完成 |
| C12 范围恢复 | 媒体/接口多范围暂停、缓存命中、旧许可和重启组合 | 一个范围的成功不能清除其它暂停；过期代次、仅下载或缓存命中不证明目标阶段恢复 |

每个组合同时核对持久状态、来源、实际渠道记录和请求归属。取消与修订通过真实入站及任务控制路径；渠道等待时先让出队列，不能在占有发送队列时等待同队列里的控制消息。

## 语义校准的本地部分

扩充人工标注的正反例及保留样本：观察范围、空缓存、回复条件、真假混合、旧自述、来源类别、数字/时间/单位、采样与完整覆盖、未知发送及恢复状态。合理的“无法确认”可接受；在不确定措辞后夹带确定结论应拒绝。

程序回归核对逐段完整性、重复或未知证据 ID、来源类别保留、服务失败与语义拒绝分离、证据包在修稿中的复用。离线回放分别报告误放、误拒、无响应和未执行，并按校准/保留集分开统计。脚本响应只检验协议与审计，不能作为模型事实判断可靠性的证明。

准备待真实复验的输入包及空观察模板，带语料摘要和每例实际输入摘要；不自动调用模型或把预期答案填成真实观察。真实语义复验和第三轮整体退出条件保持未满足，直到授权范围内的真实证据取得。
