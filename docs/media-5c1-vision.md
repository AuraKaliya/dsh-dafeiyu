# 统一媒体5C-1：图像曝光、独立分析和选择性记忆

2026-10-25；基线`b9e6af9`。

新增可装配的MediaService，串行取得／解码作业、固定来源provider、实际core作用域、取消、租约与恢复。提供取得、检查、图像／指定帧读取及观察选择动作。统一Host的profile和迁移装配留在5F，本步通过真实本地DSH装配检查。

实际FFmpeg归一化后的图像以image block进入独立DSH会话。宿主附件路由采用每次分析独立随机引用，并以异步调用作用域限制读取；其它会话不能借引用读取。引用改动、来源失效、分析结束、缺少image路由声明、模型没有实际取得附件字节均拒绝形成观察。模型要求比已有归一化图像更小的请求上限时明确拒绝，不假称已缩放；后续可增补请求尺寸适配。

分析没有主聊天人格、历史或工具。输出为严格有界JSON，每张图片恰好对应一个索引；推断、可见文字和不确定性分列。reasoning和不透明replay在进入独立DSH持久层前剔除。程序固定实际尺寸、PTS、字节hash、来源谱系和音轨／未采样缺口，视觉输出始终标为模型推断，不能声称观看完整视频。

媒体曝光保存于独立库，再接现有能力观察／选择接口；只有实际工具结果曝光后才可选择保存。默认读取不创建长期记忆。源撤回、逻辑删除原资产或派生资产会阻断旧观察；普通缓存回收保留“当时看过”的历史覆盖。原图、帧和推断沿用根来源，不增加独立证据数。原始多媒体取得引用不提供主人指令权限。
