## 已实现

runtime v3追加独立native_deliveries及不可变锚点／材料／凭据保护。每个Run唯一交付意图；模型重试或重复程序请求不再生成或发送。ready的现有正文可以在恢复并重新验证后发送；sending重开为uncertain，rendering／verifying重开为interrupted。部分确认、未知和未发状态分别保存，未知不自动续发。旧D3仍只允许显式模拟渠道且受旧锚点限制。

新deliverTaskResult通道接口绑定真实原始入站、Task／Run／epoch、目标、来源戳及有效期。新群闲聊和缓存淘汰不更换锚点；引用ID来自真实Journal。每段重查来源、人格、范围和取消，发送副本与持久计划一致，调用方修改对象不能改目标／正文。

整理使用独立、真实持久的DSH会话，读取正式底色及当前目标范围可验证的阶段投影；全局未声明提示、其它群历史及执行会话不继承，工具调用拒绝，内部思考不归档。独立校验失败不生成发送凭据。阶段来源在生成中撤回，会阻止发送。

阻断异议可生成明确的等待通知，Run仍保持waiting，不宣称任务完成。真实解决消息作为补充来源随继续链保存；其撤回使继续结果不可用。兴趣探索的内部目标／理由不通过状态原文泄漏，明确任务标题由真实指示生成。

已发任务正文在QQ缓存中只留明确占位，避免它被当成无依赖的新事实重复记入。核心为同一目标会话提供最近结果的有界节选（每份最多1000个Unicode码点，并说明是否完整）；来源失效即撤下。这里没有完整任务结果的历史分页阅读工具。发送授权到期不抹掉仍可核验的已发表内容。控制操作的程序回执有独立上下文，避免撤下旧答案后连取消事实也看不到。
