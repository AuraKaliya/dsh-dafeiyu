# 大肥鱼管理中心 · 当前原型 v4

本目录仅用于设计讨论，不是 DSH 插件实现。未修改业务包、依赖、配置协议或真实数据，未安装部署。账号、素材和状态均为示例；修改只保存在当前浏览器内存，刷新恢复。

直接打开 index.html，或在项目根目录运行：

```powershell
node docs/prototypes/management-center/serve.mjs 63578
```

省略端口时随机选择回环端口。服务只提供固定页面资源，没有业务 API；CSP 禁止连接外部服务。

## 当前结构

六个横向页签：总览、人格与记忆、能力、任务与记录、提示词预览、运行。只使用 DSH 设置工作区，不新增常驻侧栏；原型外框可隐藏。

能力包括 QQ、B站、多媒体、DSH 工具、自主活动和系统执行。B站已有功能的 UI 保留；发表评论、发布弹幕等扩展功能不纳入。

QQ 分为连接组件、饲养员身份、消息收发。消息收发内按七项独立管理：可观察群列表、自然称呼、限时观察窗口、连续消息合并、自然聊天延迟、表情包管理、多媒体处理。其他页面也按单一职责拆分。

表情包提供预览、搜索、名称/标签/说明编辑、停用、删除和恢复；不扩大素材来源范围，不修改历史使用记录。缩略图为原型自绘 SVG 示例。

提示词直接渲染源码固定文字，按模块着色并提供跳转；动态正文统一为【动态提示词】。固定条目可展开，独立视觉分析按独立请求呈现。

活动经费以万 Token 为单位，默认 10。有效触发后先执行一次活动，活动结束后累计经费和时长，再判断是否继续。允许活动完成时超过预算，不设硬上限或额度预留。

## 文件与依据

- prototype.js：通用壳、记忆示例、导航与对话框。
- design-pages.js：配置草稿、任务示例及交互处理。
- panels.js：单一职责页面、表情素材管理和固定提示词文案。
- prompt-layout.js：区分当前代码分层与缓存优化草案的只读预览。
- prototype.css：离线原型样式，正式实现另接 DSH 主题。
- prompt-sources.json：固定提示词来源与哈希。
- [前后端功能规格](前后端功能规格.md)：当前行为与未来接口边界。
- [DSH 接口核对](../../references/dsh-ui/接口核对与设计依据.md)：官方资料与版本依据。

本轮只做短交互和脚本语法检查，不运行业务全量回归。最新截图为 screenshots/v4-*.png；此前图片为历史原型，不代表当前规格。
