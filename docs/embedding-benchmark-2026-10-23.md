# 中文记忆 embedding 本机评测与选型

日期：2026-10-23（北京时间）。状态：两模型 CPU／CUDA 四组真实本机推理完成；尚未接入运行中的记忆插件、QQ 或服务器。

## 结论

首版中文语义召回选择 **BAAI/bge-small-zh-v1.5，512 维，本地 CPU 运行优先**。保留 Qwen3-Embedding-0.6B 作为可替换对照，不默认同时运行两个模型。

43 个有答案查询中，BGE 的 Recall@5 为 95.35%，Qwen 为 97.67%，Qwen 多完整召回一题。Qwen 的 CPU 查询 P95 约为 BGE 的 23.7 倍，CPU 进程峰值工作集约为 5.8 倍；本机 GPU 运行同样没有消除两者的资源差距。

运行前规则规定：Qwen 的 Recall@5 提升至少 5 个百分点且延迟达标才优先采用。实际提升 2.33 个百分点，因此本次选择 BGE。该结果支持首版轻量基线，并不证明 BGE 在所有中文任务上优于 Qwen。

## 样本与指标口径

固定 100 条手工构造的虚构中文记忆，47 个查询：43 个有答案查询、4 个无答案查询。查询和相关标签在模型运行前冻结，文件 SHA256 保存于每个结果文件；未根据结果改标签、问题或排序参数。

有答案查询包括中文改写 6、否定与转述 6、近似编号 4、时间变化 6、关系理解 6、中英混合 4、短姓名 4、多条证据 4、状态过滤 3。

Recall@5 为逐查询相关证据覆盖率的宏平均；多条证据问题需要覆盖所有标注依据。Hit@1 表示第一条是否为相关证据，不等于最终答案正确率。4 个无答案查询不计入召回率，单独查看相似度与候选行为。

状态过滤来自评测器确定性规则，不能算作模型学会了权限控制。去掉 3 个状态过滤问题后，40 个内容检索问题的 BGE Recall@5 为 95.00%，Qwen 为 97.50%。

## 召回结果

CPU 和 CUDA 的下表指标一致。

| 方式 | Hit@1 | Recall@5 | MRR@10 |
|---|---:|---:|---:|
| 字符 n-gram BM25 基线 | 58.14% | 93.02% | 0.7314 |
| BGE 向量 | 74.42% | 95.35% | 0.8450 |
| Qwen 向量 | 76.74% | 97.67% | 0.8624 |
| BGE＋BM25，固定 RRF k=60 | 79.07% | 95.35% | 0.8651 |
| Qwen＋BM25，固定 RRF k=60 | 76.74% | 97.67% | 0.8682 |

这里 BM25 是包含中文单字／双字及拉丁标识符的简单基线，不是经过调优的生产全文搜索。RRF 参数在运行前固定。本样本上，BGE 混合召回改善了第一条证据排序，但未增加 Top-5 覆盖；不能据此宣称混合检索一定改善所有指标。

## 失败案例及设计含义

### 工作情境关联：两模型均漏召回

问题 `q26`：“同样是真实记忆，为什么排错时不该把香味偏好一起塞进上下文？”

标注目标为当前正在排查消息引用故障、应优先检索定位和操作记录的材料。两模型均将其排在 Top-5 之外，更多召回记忆管理原则或香味偏好本身。

这是一道需要联系当前工作情境的解释题，相关性标注具有解释空间，不是严格的事实问答标准。保留原标签和结果，未事后调整分数。实际插件需要将当前任务状态用于检索规划，不能仅凭问句向量实现有效注意力。

### 短姓名与角色关联：BGE 漏召回，Qwen 成功

问题 `q35`：“谁在查漏掉的日志记录？”

目标原文为“月舟负责检查日志缺失，岳舟负责修改界面颜色，二者职责不同”。BGE 未将该条排进 Top-5，Qwen 成功召回。这是 Qwen 本次 Top-5 增益的来源；首版应保留实体、职责及同义表达的关联检索设计，不能宣称 BGE 已解决所有短姓名问题。

### 高相似度不能当作有答案

4 个无答案查询在范围及状态过滤后仍会返回其他候选。BGE 最高相似度约 0.415～0.572，Qwen 约 0.400～0.530；本实验没有设置或拟合拒答阈值。这些值不能当跨模型通用阈值，也不能解释为可信概率。

正常模式没有返回其他会话或已删除样本；专门查找已删除样本时可返回指定记录。这只验证评测器的过滤路径，不代表尚未开发的记忆插件已通过删除和权限验收。

## 对开发方案的具体调整

1. 首版采用 BGE-small-zh-v1.5、512 维，本地 CPU 优先；可配置 GPU，但本机短查询不要求占用显卡。
2. M2 阶段同步接入精确／全文与小型 embedding，不再把语义检索全部推迟到 M6。
3. 固定查询指令、池化、归一化、分词器和模型版本，作为 embedding profile 记录；向量缓存不仅绑定文本，还绑定整个 profile。
4. 候选检索默认设计为关键词＋语义多路召回，RRF 作为待真实场景验证的起点，不将本次参数宣称为最优。
5. 输入按语义单元切片并保留来源；本轮只覆盖最长 52 token 的短材料，较长片段和跨片段关联仍列入后续验收。
6. 权限、有效状态和逻辑删除仍由程序过滤；embedding 相似度不授予权限，也不代替关系判断或独立分析。
7. Qwen 保留为候选后端。在更大的独立样本集显示稳定收益后，再考虑替换或按明确策略使用，不默认双模型常驻。
8. 部署格式暂不锁定为 ONNX 或量化版本；若转换或量化，必须重新核对召回和资源指标。
