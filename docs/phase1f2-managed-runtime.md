# 1F-2：统一装配、准入与关闭

日期：2026-10-24。基线`47e021b`。本步使用本机隔离profile、脚本模型和本机OneBot模拟端点；没有真实QQ登录，没有连接或修改大肥鱼服务器。

## 实现

[ManagedHost](../packages/host/src/runtime.ts)复用DSH、核心、时间线、记忆和现有渠道，提供统一装配、恢复、准入、任务运行、快照及关闭。配置和路径在预检、取得占用之后再核验；必需包／schema／模型路由／人格／动作清单不合格时，模型运行前明确失败。

运行顺序为只读检查→占用→打开DSH／提供者→绑定插件→恢复持久状态→准备渠道→开放准入。新增核心延迟准入选项，默认旧行为不变；Host准备期间核心虽具备渠道启动前提，仍拒绝聊天／任务输入且不调度模型。QQ暂存这段时间内到达的输入，使用有界缓冲；只有Host就绪后才交给核心。后台分析同样等待准入。

本步区分两种运行模式：

- **daemon**：开放已配置渠道、后台工作和已受理队列，保持状态心跳；只在明确关闭或故障时收尾。
- **single-run**：不启动QQ接收，不启动旧聊天／任务积压或后台分析，只允许本次明确提交的原生请求。已有已完成requestId返回持久结果，不重复模型／操作。没有增加跨进程控制接口。

可选QQ配置不可用时显示degraded，基础任务仍可运行；必需QQ不可用阻止开放。未知异常不会以“可选”为理由掩盖半套装配成功。未实现的activity／media／bilibili明确not-configured。memory诊断区分基础生命周期、分析工作者及仅已配置、尚未探测的检索／压缩服务。

关闭先停收、关闭准入及停止新后台任务，保持memory等提供者存活以完成当前任务和结果读取；排空期限后传播合作式取消，再等待收尾和关闭存储。未知效果保留，不能把超时当作没有执行。没有强杀进程或关闭仍被操作使用的数据库；不合作的扩展不能被假报为已安全停止。

状态快照保存Host身份、时间、配置／启动底色哈希、包版本、实际特性、准入、队列与各存储outbox计数，不保存任务／人格正文、凭据或原始异常。凭据通过既有DSH服务读取，运行结束核对文件指纹，无复制／迁移凭据。CLI需在加载DSH之前绑定本进程的隔离DSH_HOME；正式命令在1F-3实现。
