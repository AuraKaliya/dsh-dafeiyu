# 干净环境部署与调通范围

2026-10-27。服务器DSH由用户手动清理。本项目不再接管旧QQ/B站插件、旧history.sqlite、旧23点版本流程或旧更新守护。代码、功能和稳定性测试均在本机完成。

## 本机正式运行与服务器发布来源

用户2026-10-27进一步确认本机也作为正式实例使用。开发仓库通过DSH插件管理的本地 `link:` 来源安装；实例配置、身份、记忆、会话和原版OneBot运行材料放在仓库之外。本机迭代先停用插件、完成相关测试和构建，再启用同一实例，不能用测试库覆盖正式数据。安装与首次真实通信见 [本机部署检查](checks/local-dsh-deployment-20261027.md)。

服务器后续只安装、更新GitHub上经过本机检查并冻结的发布版插件；记录发布标签/版本及下载材料校验值。服务器不链接本机开发目录，不靠复制工作树更新，也不自动追踪未冻结分支。QQ登录、凭据和实例数据仍留在各自机器。此次仅部署本机，未连接或更新服务器，也未将这次本机安装表述为新的GitHub发布。

## 本机交付

1. 冻结保留功能、候选提交、锁文件、构建、底色、公开配置和本机证据清单。
2. 完成本机相关检查、162项真实模型场景、本机QQ/B站与音画验收、本机持续运行/恢复；发布前在本机做一次全量回归。
3. 在本机生成按角色分开的部署材料：DSH基础/Node依赖、项目程序、配置模板、外部模型与媒体依赖清单、初始化说明、启动说明和文件hash。不打包真实登录态、密钥、测试临时库、正式验收原始材料或私人记忆。

## 服务器只部署调通

- 核对用户清理后的目标路径、Node/DSH版本、磁盘和所需外部工具是否可用。
- 安装本机冻结的程序，设置服务器自己的凭据/平台登录态与数据路径；显式建立本项目新profile。B站私信设置固定双方UID及首次接收起点。
- 启动一次，确认进程、配置、账号绑定、渠道连接、持久路径和权限符合部署配置。必要的最小连接/收发确认按实际授权进行，不重放旧消息、不发布公开测试评论/弹幕。
- 保存简短调通结果；仅实际收到平台回执才确认平台接受。本轮一次QQ问候授权已在本机正式启动后使用，服务器后续通信按届时明确授权进行，不自动再发问候。

服务器不跑162场景、不跑全量/定向测试套件、不跑长稳/压力/故障注入/回滚演练，不做语义评分。遇到产品缺陷回本机复现、修复和相关复测，再更新部署材料。必要的启动日志与连接核对属于部署调通，不记为功能验收通过。

## 仍需准备的实际接线

独立ManagedHost与官方headless执行器代码已有；真正的无人值守生产启动还需提供共享计量程序端口。没有完整运营资金授权系统，不创建资金窗口/批准文件/增额链。当前server-runtime的命令行工具仅做inspect/status；start/run为受信程序API，不能宣称运营启动脚本已经全部完成。

媒体还需实际配置FFmpeg/ffprobe、视觉路由、ASR/声音事件处理器、文档/TTS可选依赖；配置缺失时报告能力不可用。B站私信使用项目自带API适配器，不安装或调用旧bili-lite插件。新维护与自主活动沿用本项目已实现的调度；夜间自动Git日志与自动更新守护不属于本轮部署门槛。
