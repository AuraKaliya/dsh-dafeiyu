# 记忆与信息处理方案

状态：已确认的开发设计；0.3.0已实现行为时间线检索和来源回查基础，见phase-3-timeline.md。分析、长期记忆和专用压缩尚未实现。

后续完整开发方案见 [记忆能力插件完整开发方案](memory-plugin-plan.md)。四类记忆、逻辑删除及恢复、关系相关性、独立分析与上下文装配以该方案为准；本文保留原始设计背景，不表示新增功能已实现。删除默认采用可查询、可恢复的逻辑删除，物理清除不属于普通记忆接口。

## 五类数据

| 类别 | 职责 | 所有者 |
|---|---|---|
| 原始证据 | 收到的原文、工具实际结果、附件 | DSH会话持久化及附件能力；会话外资料单独引用 |
| 行为记录 | 哪个插件何时做了什么、因何发生、结果如何 | 大肥鱼统一事件服务 |
| 信息分析 | 指代、主张、矛盾、相关性及不确定性 | 分析能力，版本化保存 |
| 工作上下文 | 当前话题、未完成事项、近期消息、压缩检查点 | DSH会话及大肥鱼上下文策略 |
| 长期记忆 | 经历、知识、偏好关系、行为经验 | 记忆能力 |

原文存在不意味着内容真实；模型摘要不是新的证据；长期保存不意味着每轮全部注入。

## 时序与因果

所有操作应由程序自动记录。事件保留全局入库序号、唯一ID、来源发生时间、接收时间、插件与版本、智能体、会话、任务/活动关联、操作ID、原因事件、来源引用、可见范围和结构版本。

入库顺序不等于跨系统真实发生顺序。消息可能迟到；以来源时间和因果引用解释时间线，不单凭时间戳建立因果关系。

同一操作记录开始和结果；任务完成和回复发送成功分别记录。执行器宣称完成不自动等于独立核实。外部状态未知要明确保存未知。

会话原文仍由DSH拥有，行为事件引用 `sessionId + seq`。会话外行为可保存必要资料到能力自己的存储，再以稳定引用关联。跨存储采用稳定标识、游标、去重与补录，不宣称分布式事务或端到端恰好一次。

第一阶段：SQLite事务内一并写入接收/状态与对应事件；事件仅追加；操作开始和结束用相同operationId；来源按会话隔离查询。审计事件不写原始异常、操作参数、操作结果或模型内部思考，详细模型输入输出由DSH按其格式保存。未来导入记忆的DSH投影必须过滤内部思考和凭据；并不声称DSH底层原始日志已经由本插件全面脱敏。

## 压缩策略

复用DSH的原始会话日志、当前上下文投影、压缩生命周期、token测量和历史查询。压缩替换当前模型可见内容，不物理删除原始记录。

大肥鱼检查点应保留：场景参与者、当前话题、明确约定与纠正、未完成任务、关键行为结果、理解对话所需的关系背景、证据引用目录。不确定主张仍保留不确定性，不能把玩笑压缩成稳定偏好。

近期原话按预算保留；固定人格独立装配；当前任务状态独立保存。对工具输出、检索材料和插件说明分别限制输入体积。压缩失败不能以空摘要替换历史。取消、并发变更和持久化失败要沿用DSH的恢复约定。

多次摘要保留覆盖范围、生成版本与原始引用；必要时回查原文，避免反复总结使推测越来越确定。摘要不自动升格为长期记忆，也不能触发历史指令。

本机参考源码 `687f282e86` 的 compaction-basic 使用固定英文编程摘要模板，当前配置没有摘要提示词字段。因此后续通过压缩服务接口实现适用策略，或增加可维护的策略扩展点；不能假定只改配置即完成定制。插件限定在大肥鱼作用域，同一会话不能同时运行两个压缩提供方。具体选择需用锁定的发布包验证，不直接修改DSH主循环。

## 归档和检索

事件产生时即持久化，不等上下文满了才归档。冷热分层是后续存储优化；迁移前验证数据可读性，稳定引用不能失效。

检索顺序：先确定可见范围 → 时间/人物/任务/插件等精确过滤与全文/语义检索 → 返回摘要和来源 → 按需打开邻近原文。检索结果也需记录本轮实际使用来源，保持模型输入可回查。

DSH原有会话查询服务负责原始会话与全文检索；大肥鱼补充跨插件行为、长期记忆及可见范围，不重新复制整套会话库。索引可由有效原记录重建；不能通过重放历史再次执行发送、发布或命令。

派生摘要、分析和向量索引继承其来源范围。跨来源结果只允许在全部相关来源均可见的上下文使用，或拆成独立条目。统一存储不代表各群可看彼此原文。

## 信息分析

1. 接收层：程序确定性记录身份标识、时间、引用、重复和来源，不让模型猜真实身份。
2. 当前理解层：按需分析指代、主张、话题、事实陈述、玩笑、矛盾和相关性。
3. 后台整理层：增量合并经历、知识、偏好及关系，不对每个心跳重复调用模型。

分析条目记录：谁提出什么主张、主张对象、有效时间、直接观察/本人陈述/转述/推断、支持与冲突证据、歧义、分析版本和记忆候选类型。模型信心不是校准后的概率。

获取字幕只证明读取了字幕，不证明看到了画面；网页中的观点不自动成为事实；讨论过某观点不意味着大肥鱼认同它。分析缺失或失败标记未分析，不默认正确。

新澄清可以替代旧判断并标记受影响的记忆与摘要；保留修正关系。高频技术事件通常做统计，有意义的失败、承诺和变化才形成经历记忆。

## 长期记忆与遗忘

长期记忆分经历、知识、偏好关系、行为经验。每项包含来源、适用时间、可见范围、状态及版本。固定人格不会由后台整理任意改写。

停止使用某项长期记忆与物理删除原始归档是不同操作，需按用户意图区分。撤回标记必须作用到检索、摘要和索引重建，防止被忘记的事实再次进入记忆。既有已删除档案不恢复；后续真实新增记录要保留。

## 后续验证重点

- 迟到事件、并行插件和因果顺序。
- 相同消息或事件重复到达只形成一份有效记录。
- 摘要保持不确定性、原话纠正和未完成事项。
- 跨群/私聊权限在检索前生效，派生数据不扩大可见范围。
- 分析更正能定位受影响记忆；遗忘后重建不复活。
- 大工具输出、压缩失败、多次摘要后仍能找到原始证据。
