# R6f-3 固定 B站生产 transport 检查

2026-10-27，北京时间。已完成生产接口与同机消费者租约，本地定向通过；尚未接收真实 B站消息或向平台发送内容。本批不切换服务器。

## 接线与范围

生产工厂只加载服务器固定路径、经 SHA256 验证的现行 BiliAuth 完整字节，不加载旧 BiliAccount、worker、HistoryStore 或全局工具。账号固定 `170759822`、唯一主人 `13461350`；请求仅限登录身份核对、读取双方私信与发送主人私信三个 endpoint。登录态始终由服务器进程内的 Auth 使用，不复制到本地。

生产 manifest 指定公开配置指纹、固定合同代际及旧消费者交接证据。身份与来源 stamp 只依赖账号、主人、合同和代际；cookie 刷新、进程重启和无关公开配置改动后重新核验，不自然改变来源身份。公开 pins 的运行中变化仍使当前实例停止接线。

有界响应在 JSON 解析前保留精确消息 ID；读取核对双方、类型、时间及分页。发送再次核验活授权、实际正文指纹和固定收件人，最多 1000 个 Unicode codepoint。发生 POST 后，缺回执、取消、断链或平台风险均保留 unknown，不自动重试；幂等沿用已提交渠道 ledger。

固定 Windows named pipe 排除本实现的重复消费者；不同 profile 不能通过换路径绕过，进程退出后由 OS 释放。旧实现不认识该租约，仍须部署时停止并核验。manifest 的 `oldConsumersStopped` 声明和 lease 成功都不替代实际交接验收。

公开测试夹具已内置到项目，以现网/管理材料同 SHA256 的公开 Auth 源码为依据，不依赖管理中心目录，不含真实凭据。生产仍核验服务器原文件，不能用此夹具覆盖现网。
