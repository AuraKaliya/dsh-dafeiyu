# 统一媒体5C-3：有界文档读取

2026-10-25；基线`0ce5b34`。

媒体动作接入实际文档工作进程，支持严格UTF-8／显式UTF-16 BOM文本、CSV、JSON、PDF文本层、DOCX正文段落／表格及XLSX已有单元格值。所有输入为已获准资产；读取前核对字节hash，结果绑定同一hash。每个片段保留页／段／行／单元格定位；长单元返回`next.offset`和`next.textOffset`，可继续读取。字符游标按Unicode字符计数，输出预算按UTF-16长度计，避免emoji截断和不前进游标。

文档至多16 MiB；压缩包在读取前核对成员数量、大小、合计展开量、压缩比、重复／越界／链接成员和宏。直接读取成员，不在磁盘展开。XML禁止DTD／实体声明，包括UTF-16编码。DOCX仅正文／表格，XLSX只取已有值，公式不计算，外部关系不访问。

PDF使用固定pypdf 6.10.0接口，限制页面和解压输出，不调用外部图像解码器；不执行PDF动作、脚本或附件。无文本层的页面明确标注“未做OCR”。没有正文的结果只报告缺口，不制造“已理解”观察或可选择的正文记忆。复杂版面和图片仍未覆盖。

实际运行：受限Python工作进程、真实合成文本／DOCX／XLSX／PDF解析、SQLite和核心媒体动作；没有文档模型调用。Python使用本机现有工作依赖路径，未下载或安装新依赖，临时文件仍在D盘；最终Host配置和部署依赖核验留在5F／部署阶段，不假定服务器可用。
