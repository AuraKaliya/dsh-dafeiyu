# R6b-1：部署长期授权文件读取与持续校验

2026-10-26。此检查点只实现独立长期授权文件及校验器；完整 DSH 插件装配、真实管理员子进程、生产预算及服务器切换尚未完成。

## 实现范围

新增 `@dafeiyu/server-bootstrap` 包的 `StandingAuthorityFile`。它接收部署维护者固定的配置目录、文件路径、授权 ID、版本和 SHA-256，不接收模型提供的路径。文件以严格结构校验，限定大小，拒绝未知字段，并核对实际物理路径没有通过目录联接逃出配置目录。

授权需要未撤销、处于有效期，且与真实 Core 授权中的智能体、活动来源、政策和动作一致。自主分支只允许 `activity-wake` 和 `self-exploration`；主人任务另行核验，不把自主活动改写成主人命令。工作目录必须落在授权的实际目录内。返回的许可绑定原 Core guard 和文件 hash，每次重验撤销、过期、配置变更及目录重定向。

文件提供预算授权 ID 和单次执行时间，不能自行创建预算或修改原验收时钟。这里的目录检查约束入口的工作目录，不是管理员进程的操作系统沙箱，也不声称阻止所有任意命令访问其它目录。

## 兼容与数据

不改动现有人格、成长状态、Core/Memory 数据库或历史 Run，不读取旧人格文件、账号凭据或私人记忆。普通启动不会写入、生成或自动延长长期授权。部署时另行生成正式记录并绑定实际路径；虚构样本不进入生产。
