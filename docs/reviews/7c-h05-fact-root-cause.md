## 可支持与不能支持的根因结论

可以支持的是：

1. **不是夹具漏输入。** 第3/6条真正出现在使用的基线会话，并获得可见回应。
2. **没有发现摘要删掉或否定该fact。** 直接否定限定在有效摘要中完整保留，投影和活动选择均可核。
3. **没有发现最终DSH请求来源漏装。** 工具调用前后两次请求都引用含该fact的摘要。
4. **最终答案覆盖不足。** 已知事实可用而没有在答案中交付，符合保留2/3的观察。

不能由这些材料确定的是：模型是否因简洁作答而省略、是否把便笺视为与最后问题不直接相关、是否受摘要中行政性等待记录的密度影响，或是否存在远端的注意力差异。这里的“答案层遗漏”是故障所在层的判定，不是关于模型内部原因的声明。

问题与量表存在一个需要保持清楚的测量边界：最后问题直接问A/B状态与能否重做，没有单独要求列出便笺。comp2用确认回执和未知效果已经解释了不能重做，却仍未满足冻结的第三个正向fact。**这说明当前评分测量的是要求的答案事实覆盖，不能直接等同“模型已忘掉这条记录”。** 这一解释不撤销已冻结的评分，也不把第三个fact从分母删除。

| 观察到的首个缺口 | 可优先定位的环节 |
