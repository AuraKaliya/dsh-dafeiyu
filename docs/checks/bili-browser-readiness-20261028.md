# B站浏览器异步就绪修复

2026-10-28，本机正式实例停用后备份最新数据，再更新所链接的开发仓库；未操作服务器。保留既有人格、记忆、会话与账号绑定。

## 原因与修复

旧适配器在打开页面后立刻读取头像链接，将空列表与其他账号一并归为 ACCOUNT_MISMATCH。没有额外人工延时的组件检查已经复现此误判。

现在页面导航后共享一个 10 秒就绪预算，每 250 毫秒只读取现有 DOM。账号未出现继续等待；出现明确的其他 UID 立即拒绝；超时单独记录 BILI_BROWSER_IDENTITY_UNAVAILABLE，不把加载失败写成登录错误或持久锁定。重复的同账号头像链接不产生歧义。等待支持调用者取消，不刷新页面、重复导航或自动重试 API。

评论仅在实际评论节点产生文字后返回，空容器和未挂载评论继续等待；视频等待标题挂载。账号检查、滚动与内容等待共用预算，内容超时为 BILI_BROWSER_CONTENT_UNAVAILABLE。最终交付前再次核对账号和页面 URL；保留打开时的验证挑战检查与原有退避门禁。
