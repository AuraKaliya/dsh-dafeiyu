## 长任务的上下文边界

完整资料、评论去重集、阅读记录和原始证据留在后端；模型携带有界的最近记录、未结束条目、总进度和交接摘要。原始依据可以在最终交付时核验，不需要把旧会话全文重新塞回新段。

默认软限 24,000、硬限 32,000 输入 token；还会按模型窗口和输出预留进一步收紧。采用实际请求计量器的估计值，删除旧的“字节数除以 4”入口。无进展的超大首请求明确失败，避免空段循环。总期限不因续段重置，最多 8 段；达到限制会保留进度并报告原因。

20 视频测试中所有已准入请求的估计输入量均低于 32,000 token；记录的单次消息最大大小为 **33,305 字节**，这不是 token 数。累计消耗随工作增长属正常；控制对象是单次请求上下文和重复读取。该测试使用真实 Host、DSH 执行循环与 SQLite，外部模型及平台响应为固定测试数据，不是线上性能基准。
