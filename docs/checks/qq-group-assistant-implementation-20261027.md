# QQ 群助手统一过滤：实现与本机检查

日期：2026-10-27（北京时间）。基于前次[原版只读验证](qq-group-assistant-sendpacket-20261027.md)，按用户授权在本项目内实现。未部署、未推送发布、未发送真实 QQ 消息，未迁移真实运行数据；SnowLuma 代码保持原版。

## 行为与边界

过滤只使用既有群列表入口和同一个同步计时器，频率仍由 `groupSync.intervalMs` 控制，默认30秒。设置变化在下一次成功的群列表同步确认后生效。成员关系快照保留所有实际加入群，有效名单只包含允许范围内的普通接收（1）和免打扰（4）；群助手（2）、屏蔽（3）和未知档位均无自动处理资格。

- 群助手消息在缓存、媒体登记、任务受理及模型入站之前被拦截，@、称呼、引用和普通消息共用这条入口。
- 群浏览、观察／记忆选择、媒体访问和逐段发送共用 `GroupDirectory.effective()`，没有第二份可绕过的群名单。
- 移入群助手撤销正在使用的群处理信号，阻止排队对话、正在生成的普通回复、由该群发起的原生任务及正在整理的任务结果继续自动处理／发送。
- 移出后从下一个整秒接收新消息，可能有不足一秒的保守间隔；迟到的忽略期间消息不进入缓存或模型。重启先重新成功读取状态，不能直接从磁盘旧名单恢复权限。
- 群每次恢复拥有新的持久资格代次，入站元数据记录其代次。旧队列／结果即使在恢复后才继续，也不能借用新资格。原会话、缓存、回执及既有记忆保留。
- 程序侧以被动缓存消息为来源的合法回复仍受当前代次、原接收时间和逐段权限核验，不强制将被动消息伪造成模型入站。
- 已发生的外部效果仍按既有回执记录；取消不回滚副作用，也不重新派发已开始的动作。

## 实现位置

| 位置 | 实现 |
|---|---|
| `packages/channel-qq/src/snowluma-groups.ts` | 固定已实测的 `0xfe5_2` 只读请求；有长度／字段／重复值／UTF-8／群数限制的 protobuf 解析；未知档位显式为空 |
| `onebot.ts` | `groups()` 在前后账号核验之间执行固定 `send_packet`；不先请求标准列表，不按群另行查询，不提供模型可填的任意原始协议接口 |
| `groups.ts` | 同步、有效名单、群处理信号、接收边界和状态诊断统一管理；不新增调度器 |
| `store.ts`、`cache.ts`、`schema.ts` | 群快照与消息元数据持久记录资格代次，群快照事务提交；QQ数据版本6 |
| `packages/contracts/src/index.ts` | 可选的程序侧渠道处理信号；不接受模型传入 |
| `packages/core/src/index.ts`、`execution-coordinator.ts`、`registry-v3.ts` | v2／v3注册时保留方法接收者；信号进入排队／在途对话、消息来源任务和任务结果交付链 |
| `packages/plugin/src/installation.ts` | allowlist和joined安装均启用同一个群目录；`joinedGroups:false`不再绕过状态读取 |

状态读取缺失或不支持时不回退成未过滤的标准群列表。新进程缺少成功读取时拒绝群访问，主人私聊独立可用。后续读取失败沿用既有、可配置的陈旧期，默认最多120秒；超过期限撤销群资格。接口不支持、异常响应、部分状态未知分别显示 `GROUP_SETTINGS_UNAVAILABLE`、`GROUP_RESPONSE_INVALID`、`GROUP_SETTINGS_UNKNOWN`。

## 配置与数据兼容

`groupSync.enabled`现在默认true，默认mode仍为allowlist，不扩大配置群范围。显式false只保留私聊，不再直接使用静态群号授予群资格。joined模式仍需主动选择。

QQ库由v5升至v6，新增的是版本化JSON中的接收状态、恢复时间和资格代次，不删除原消息、回执或记忆。旧库普通启动会明确要求备份迁移；Host已有迁移流程读取新的目标版本。旧群快照状态未知，不用于授权；缺少资格代次证明的旧群工作不自动续跑。升级后的库不能交给旧二进制继续写入。本轮只验证虚构测试库，没有打开或升级真实QQ工作库。

第二轮被动来源测试原先等待发送不会退出，定位后只终止该受管测试子进程，失败按原样记录。交付检查改为使用缓存中确实记录的代次和时间，不放宽真实来源或权限；等待首段的夹具补了有界失败路径，避免同类问题挂住整轮检查。Host非主人用例改用符合新接收边界的新消息时间，权限断言保留。语音接收夹具只增加连接就绪等待，未放宽HTTP／模型超时，也未降低来源、权限或完成状态断言。

并行语音异议失败现场：父对话记录 `MODEL_INCOMPLETE`，后续Run为 `EXECUTION_FAILED`，该次未伪称完成。单文件复检证明对应功能在本次独立运行下通过，不能据此认定并行资源／时序稳定性问题已解决。发布前仍须按既定本机稳定性及发布检查安排核验，不通过更改本轮成功标记覆盖失败。

主要新增覆盖：

- 群助手与免打扰分开、未知／缺失字段、错误账号、拒绝／畸形／过量响应、重复群、非法编码、固定只读命令不回退。
- 静态名单旁路关闭、一个周期且串行刷新、某群收进助手后正在使用的信号撤销。
- @／自然称呼／被动消息均不进入缓存或模型，主人私聊保留。
- 同一秒内移入并移出仍取消原代次工作；恢复／重启丢弃忽略期间旧消息；原会话和记录保留。
- 群浏览与记忆选择不再访问忽略群，后台任务及正在整理的任务结果取消。
- v5显式迁移、旧数据字节保护、原回执保留、v2／v3处理信号与类方法绑定。
- 媒体、语音任务、来源撤回、分段未知回执、Host装配／管理员来源、普通安装与恢复。
