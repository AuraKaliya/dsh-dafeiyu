## 实现

- 桌面组合入口通过继承的Node IPC桥接DSH现有cordis工具组合。Core中的模型直接选择步骤；宿主Agent只走官方Tools执行管线，不另运行规划模型。保留精确参数校验、源消息／唤醒授权、取消、结果记录及未知效果保护。
- 主人任务可自然受理和控制，目标仍取真实消息原文，引用不授予权限；一般群成员不能冒用主人。闲聊不会自动建Task。无必要占位时受理会话可结束为handled，不伪造发送回执。
- 支持按语义选择一轮多条文字和表情位置。群回复仅首条引用来源；首次按实际文字量延迟2—10秒，后续消息短暂停顿。每条保留回执；未知结果、撤回、群助手撤权和同一发言者的新补充阻止未发尾部。
- qq_progress将公开阶段草稿与已确认操作交回原QQ人格整理；不转发执行器报告或内部思考。最终任务结果继续经过来源和表达核验。
- Growth在既有Memory中保存有真实来源、可版本修改及撤下的QQ表达偏好。按原会话隔离，普通上下文、阶段反馈、任务结果读取同一投影；临时要求立即生效，不冒充已采用人格。
- 显式QQ待办使用现有Activity持久计划。到期触发新的Run并回原QQ会话整理，不重放旧入站，不新增群列表同步周期或第二套计划。
- 插件管理变更保存到宿主交接记录，当前交付与任务结束、空闲及来源复核通过后，由DSH安装器执行。跨进程中断保持unknown，不自动重做；没有恢复旧服务器更新守护。
