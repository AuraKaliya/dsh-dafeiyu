# 开发期测试精简记录

范围仅限本地 dafeiyu 项目。此次变更只涉及测试、测试入口、源码发布清单和开发约定，未修改业务实现。

## 清理结果

- 测试文件从 152 个缩减为 41 个：39 个基础测试文件、2 个短装配检查文件。
- 原 1,070 个用例缩减为 204 个基础用例和 3 个短装配用例。
- 直接删除多轮 QQ/B站任务、任务后处理、完整上下文/记忆生命周期、跨进程崩溃与重启、真实媒体后端、真实模型和发布包安装测试。
- 删除对应模型脚本、进程场景、Python 验收脚本和未再引用的辅助代码。剩余 6 个公共辅助文件只提供临时目录、身份、音频字节、媒体存储、检索替身和计量替身。
- 混合文件保留解析、配置、记忆查询、存储状态和权限用例，移除其中的完整流程。插件启动测试改用本地资源替身，不再启动额外子进程。
- 删除分批全量执行器。单次命令只构建一次；应用测试和工具脚本各做一次类型检查。定向检查仅编译所选测试及其导入依赖。
- 保留当前接口验证、记忆事实/反思/自我认识、会话范围隔离、幂等、权限、媒体字节校验、共享计量与存储功能的基础覆盖。
- 短装配检查仅验证一次离线 Host 启动和模拟回复，以及两个本机 OneBot HTTP 接口行为，不访问真实 QQ 平台。
- 同步调整源码发布清单，移除已删除测试的引用；没有生成、安装或发布新发行包。

## 当前命令

| 命令 | 用途 |
| --- | --- |
| `npm test` | 构建、基础测试类型检查和基础测试；不运行装配检查 |
| `npm test -- tests/autobiography.test.ts` | 只运行指定源文件的测试 |
| `npm run check` | 构建、全部保留测试的类型检查和基础测试 |
| `npm run test:smoke` | 按需运行 3 个短装配检查 |
| `npm run test:cleanup` | 清理受管理的测试临时数据 |

临时数据仍限定在项目 `.runtime/tests`，原有失败保留与磁盘预算不变。用例默认 10 秒超时。开发阶段不恢复长流程测试；局部修正只复测相关用例。
