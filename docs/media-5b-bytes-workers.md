# 统一媒体5B：实际字节、解码与回收

2026-10-25；基线`7bd3094`。

媒体取得现在实际流式写入D盘受管目录，核对长度与SHA256，完成后发布不可变对象。新增blob待发布状态，重启先把未提交对象转为清理待办，再回收文件；清理失败继续占配额。当前处理仍由后续服务按单作业串行装配，低层存储不允许多个未提交对象同时占有同一hash。活跃租约保护缓存，恢复只删除已识别的工作文件，不清理正式记录或模型权重。

范围broker只监听回环地址，每次作业使用随机入口。provider必须确认总长度和精确范围；多范围、超预算、来源失效、错误确认、悬挂读取均关闭，取消不等待不响应的provider。覆盖记录只包含实际交给响应的字节，超预算被阻断的字节不生成假的范围hash。模型不能提交URL或文件路径。

FFprobe读取实际容器，FFmpeg完成实际图片归一化、视频取帧和音轨裁剪。首版允许固定容器，禁止外部清单；MOV外部引用选项仅用于适用的格式。帧保留实际PTS，PCM按实际样本数计算覆盖并生成完整WAV头。合成PNG初次处理失败，原因是MOV专用选项误用于PNG；修复后PNG、MP4和范围流解码均通过。

Windows工作进程在挂入Job并设置提交内存限制之后才启动，限制时间、输出、子进程生命周期；取消清理整个本次进程树。环境只保留运行所需项，TMP/TEMP在D盘工作目录。512 MiB限制指进程组提交内存，不是RSS或服务器容量认证；本机实际工具为FFmpeg/ffprobe 8.1。正式接入仍需核验配置与版本。
