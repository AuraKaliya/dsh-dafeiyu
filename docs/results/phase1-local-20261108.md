## 实现要点

对外进度不另建一份可漂移的完成状态：从 Task、Run、操作、评价、交付及渠道账本生成。目标判断明确标注 `source: agent`、`programVerified: false`；旧目标代次和已被后续运行取代的记录只保留为历史，不提供当前恢复动作或发送当前故障通知。

系统通知只用有限程序措辞描述已知阶段、阻塞和可行下一步，不带主人原文、未核验正文或原始错误响应。任务通知进入原 FeedbackLedger，经原渠道队列发送；重复状态包括 sent、unknown 均复用原通知。发送异常保持未知，不走备用发送；重启后未结算认领也按未知核对。渠道异常在发送队列内归类，避免误触发全局持久化故障停机。

发送续办必须有确定未发事实或匹配的渠道分段账本；每次仍检查来源、授权、最新运行、批准正文和有效期。媒体导出只保留原有效期内的文件租约，不重新授予权限。进程中断通知由本版本新保存的中断标记触发，不扫描历史失败批量补发。

runtime v6 没有新增表；增加 Task 和运行事件查询索引，同时以结构版本隔离新的持久恢复语义。旧实例必须显式迁移，不能修改版本号来启动。回退要恢复匹配的旧程序、配置和数据库备份，不让旧程序读取升级后的数据库。
