## 固定比较结果

变更前基线由 0.28.9 / 修订 `3d04ae4` 运行生成，记录为 `0d62fce0-f016-4a4f-aebb-894bde4ec3a3`，固定文件为 `tests/fixtures/acceptance/context-baseline.json`。该文件在运行代码修改前产生，之后未调整其数值。

同一主人任务顺序读取十二份 6,000 字符材料；每份先实际暴露前 4,000 字符，最后从第一份归档续读尾部 2,000 字符。其余尾段仍明确未读。两版均为十四次任务模型请求、总共十六次请求、十二次原宿主读取、一次归档回查和一次同正文的最终交付。纠正、禁止修改文件和待办一直保留。

| --- | ---: | ---: |
| 全部适配器输入字节 | 2,158,040 | 1,388,306 |
| 任务适配器输入字节 | 2,080,151 | 1,308,525 |
| 单次任务输入峰值 | 233,069 | 106,759 |
| 十二段已读正文在后续请求中的出现总次数 | 90 | 24 |

当前测量账本记录 SDK 适配前合计 1,388,532 字节，比适配器观察值多 226 字节。SDK 在适配边界处理工具声明，所以两个观察位置不同。独立审计按请求核对适配前摘要、会话和字节到 `model_request_inputs`，比较降幅时只使用适配器侧的前后数字。十六次脚本请求全部明确标为 `deterministic-test`，供应商用量均未知，费用为 null。

查询性能样本保存约 1.5 MB 的合成结果，读取五十个指定 Unicode 字符区间。最终全量回归记录为一次文件加载、四十九次缓存命中、约 45 ms 分页处理；这是本机本轮局部测量，没有变更前同机耗时对照，不据此计算速度提升比例。缓存仍核对文件身份与状态；篡改、错误任务/会话和超范围参数被拒绝。
