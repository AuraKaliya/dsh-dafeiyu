# QQ阶段2B：自然称呼与群范围同步检查

日期：2026-10-25；接续 `ff0796d`。按照阶段2方案实现文字触发与群同步，所有执行检查都在本机隔离数据／回环替身中完成，正式模型与平台验收继续延期。

## 已实现的行为

- 可配置 `naturalNames`，支持“大肥鱼，你怎么看”“蓝色大肥鱼你怎么看”及独立文字“@蓝色大肥鱼”。识别正文直接称呼，忽略昵称、已引用正文、代码块、引用块、成对引号中的例子和“大肥鱼丸”等前缀误命中。机械解析有明确边界，不声称理解所有自然语言称呼；旧配置默认关闭。
- `groupSync`默认关闭，保留静态白名单。启用后默认每30秒按[OneBot 11公开接口](https://github.com/botuniverse/onebot-11/blob/master/api/public.md#get_group_list-获取群列表)读取群列表，前后核验登录账号。allowlist取配置和实际加入集合的交集，joined必须显式开启；后台单一计时器，不重叠、不唤醒模型。
- 成功的空列表与退群立即撤销对应群访问；同步失败保留本进程最后成功集合至陈旧期上限（默认120秒），过期拒绝群接收／发送。时间窗使用单调时钟；重新启动后的持久快照仅供历史诊断，必须重新成功刷新才有动态群权限。账号不符或快照保存失败立即撤销动态权限。
- 发送前核验账号后，再检查群范围，避免模型回复生成期间已经退群仍发送。关闭取消同步并等待当前请求收尾，排空期保留未过期范围供已有回复收尾。
- QQ状态提供同步模式、成功时间、实际／有效群和稳定错误；Host快照增加无正文的同步健康信息。同步失败显示degraded，主人私聊在账号在线时仍可用；查询状态不会调用平台或模型。

此步未加入自动入群、读取离线历史、普通群聊自动记忆、跨群权限、模型任务提交或主动发言。自然称呼只决定是否进入聊天，实际sender仍取平台envelope，不赋予主人身份。
