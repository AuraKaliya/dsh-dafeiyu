# 7C-2原生数据与摘要接线修正检查

2026-10-26，承接已提交的[修正设计](integrated-7c2-native-data-design.md)。本步为离线实现与检查，未新增真实模型调用。

## 实现

- 原生任务、核心冻结端口、记忆提供者和执行证据适配完整转发可选语义重写接口；旧提供者仍可不实现。
- 普通摘要按剩余组数分配剩余字符及片段额度，避免每组各自使用总额度；保留总大小、来源及最小收益校验。
- 保护条款或原始来源超过容量时保留该组，记录分类原因，继续检查其他独立组。未改变限定词上限、来源要求或64 token最小收益。
- 增加可选任务data，限16 KiB，沿既有身份、隐私和请求幂等校验进入带来源的原生用户消息；不改变任务目标或权限。省略字段时保持旧结构，无数据库迁移。
- 真实历史材料改走data，不再通过动态系统上下文重复暴露未压缩原文。冻结的事实、问题、八轮续接及评分标准不变。
- 摘要失败只记录安全分类；真实驱动遇到首次摘要失败即停止。支持指定单个校准项诊断，全部校准通过仍是正式162项的前置条件。
