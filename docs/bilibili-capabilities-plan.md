# 阶段6：B站首版能力开发方案

2026-10-25；代码基线`2c3e4ec`。承接总方案阶段6，先提交本文，再逐步开发。只做本地程序和虚构平台检查；真实模型、真实B站／QQ与发布全量回归留待整体阶段，不连接服务器。

## 1. 范围与既有代码

核心已有v3能力、Task／Run、实际主人任务来源和自主活动唤醒；memory v11负责观察、选择和来源失效；media v2已有真实字节区间、FFmpeg取帧／音轨、独立DSH视觉、ASR与声音事件。B站插件只负责平台对象、请求与来源登记，不自建模型循环、不直接写memory、不自行安排固定刷视频流程。搜索什么、看哪一段、是否保存，由大肥鱼决定。

本地管理中心旧`bili-lite/index.js`仅作为路径／WBI／数据字段参考。它的旧子代理、账号、私信、发布和证据目录都不迁入本项目。官方[稿件详情接口](https://openhome.bilibili.com/doc/4/d9554788-dcef-f139-6217-b487d41c3826)描述的是授权用户稿件，不能据此宣称支持公开站点的完整观看。本阶段网页读取适配器按本地已知协议实现、隔离和测试；平台兼容性保留待验，不把模拟响应当官方接口保证。

首版提供发现／搜索、视频与分P、字幕、时间段弹幕、评论／楼中楼、视频／音频源、观察选择。没有评论／弹幕发布、点赞、投币、关注或私信工具；B站渠道接口不注册。QQ仅是任务触发和已授权结果交付渠道，自主活动也使用相同能力。

## 3. 接口与依赖

新增`@dafeiyu/bilibili`，依赖contracts、core端口及media端口，运行库`core/bilibili.sqlite`。Host顺序memory→core execution→media→bilibili→QQ／activity开放入站。能力要求原生Task、来源跟踪；普通QQ聊天需先建立任务，避免直接把整段私有聊天变成平台参数。

统一公开资源场景为`{channel:'bilibili',account:'public',kind:'local',id:'public'}`。此场景须在策略中明确授权；它表示允许读取公开内容，不表示允许向平台发送私有输入。QQ兴趣任务新增显式配置的`explorationResources`，只取所属任务策略resources的子集；旧配置仍只有原会话，不能因此读其它群。自主活动继续使用既有活动策略资源范围。

动作采用严格schema和稳定错误码，所有请求有requestId；`bili_discover`、`bili_search_sources`、`bili_search`、`bili_video`、`bili_comments`、`bili_subtitles`、`bili_danmaku`、`bili_media`、`bili_observe_select`分别返回实际完成的结果、来源、覆盖和下一页位置。播放源只返回受控引用，媒体理解继续调用`dafeiyu_media_read`，不将URL送入模型。

## 4. 搜索输入与来源边界

搜索词也是对外传输。本版不接受主会话任意拼接的自由query：模型从程序提供的可核验来源选择关键词。来源包括配置的公开探索种子、当前Task实际看过的公开标题／标签／评论片段，以及真实主人任务中明确的`B站搜索：关键词`指令。选择可按Unicode范围截取，长度限制；程序从来源原文取得实际文本，模型不能替换内容。没有种子也可以先发现公开视频，再自主选择兴趣。

主人指令由核心读取实际、未撤回的主人主正文与任务来源，不能由昵称、引用、模型goal或网页内容授予；首版不从语音任务生成自由外发查询。来源变化、任务epoch改变、换Task或未曝光的页面使票据失效。自由语义改写搜索词将来需另加独立的公开来源投影，不能绕过当前出口边界。

平台信息进入统一观察端口；选择none／original／fragment／summary复用memory。网页中的命令只是数据。搜索结果、字幕、评论、弹幕分别举证；平台统计和用户言论不作为已核实世界事实。读取不自动保存为长期记忆，更不自动修改人格。

## 5. 网络、账号和恢复

适配器只发固定GET路径，参数严格白名单；不暴露任意URL／headers／Cookie工具。API域名固定，字幕与CDN按后缀边界及公开DNS地址核验、固定本次解析、HTTPS、无重定向；凭据仅用于API源站，不发给媒体CDN或字幕。流式响应、JSON／XML／protobuf解析均有长度／条数／深度限制。

默认匿名。可选本地独立会话文件及期望UID；只读取明确配置的文件，不搜索／复制管理中心或服务器登录态，不实现登录刷新和静默写Cookie。读取身份在固定nav接口核验，账号不符／未登录停止，不降级冒充成功。凭据缺失及媒体权限不足明确报告，不能绕过登录、会员或DRM。

配置最小请求间隔与超时；HTTP412／429及平台风控码进入持久退避，不自动循环重试、切账号或切代理。同一requestId返回已有页面；失败保留稳定码并允许模型稍后明确新请求。进程中断的请求标为interrupted，不在恢复时自动访问平台。

运行库保存身份元信息、不可变页面／观察引用、请求指纹、来源修订、媒体描述与私有短期定位字段、退避和审计outbox；不保存Cookie。URL／凭据不进入工具结果、统一日志、检查记录或Git。外部删除只有实际刷新发现才传播，保留最后检查时间，不宣称实时感知。

## 6. 完整音画的含义

playurl选择可解码的普通视频和音频轨；DASH分别登记，不假设视频流含音轨。来源绑定BV／aid／cid／分P、格式、轨道与取得时间；短期URL刷新若字节实体身份变化即新修订。Range必须确认总长度和实际区间，单次处理受media已有时间、字节和工作进程约束。没有可信长度或范围能力时只能在额度内完整取得，不能隐式下载大视频。

画面使用实际时间点和图像字节；声音使用真实音轨、完整请求区间的ASR与关键声音事件；字幕是独立来源。播放元数据、下载完成或有字幕都不能计为已观看。工具返回已处理区间、缺口和可继续位置，由大肥鱼决定继续、回看或换片。评论支持按页和父评论读取，弹幕按平台段号取样后按时间过滤，声明截断与不完整覆盖。

## 7. 数据迁移与验收

新profile显式启用时建立bilibili v1；已有profile首次启用须走Host迁移，先备份旧库再追加新库。关闭插件不删除库，未知版本／错身份拒绝，不覆盖memory／人格／activity／QQ。短期定位字段不导出到示例，备份仍是本机私有运行材料；Git仅提交源码、虚构测试与正式记录。

开发验收分别标注：真实本地执行（SQLite、HTTP回环、合成媒体解码）、模拟模型、模拟B站与真实平台未执行。必须检查授权资源、搜索出口、输入注入、页面来源失效、跨任务票据、412持久退避、有限响应／取消、音画分轨、QQ明确任务及兴趣、自主活动无聊天入口、记忆选择与已有迁移保护。完整模型理解质量、平台真实数据／分页／播放格式、账号绑定和持续资源开销仍列为整体待验，不能由本阶段假响应代替。
