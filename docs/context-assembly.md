# 上下文组装（v0.23）

大肥鱼把每轮材料分为三类：基础与阶段人格、当前任务责任始终保留；当前消息相关的合格记忆、同群近期背景和近期自我关注按条件自动带入；详细历史与完整工具结果由现有查询工具读取。所有材料保留来源和范围，正文不直接产生权限。

安装配置可显式启用：

```json
{
  "context": {
    "mode": "unified",
    "deadlineMs": 5000,
    "recall": { "enabled": true, "strategy": "lexical", "timeoutMs": 500 },
    "background": { "enabled": true, "windowMs": 900000 },
    "recentState": { "enabled": true, "shared": true }
  }
}
```

缺省仍为legacy。`shared`只启用独立审核的自我关注摘要政策，不能跨会话读取私聊、任务细节或第三方事实。共享仅绑定审核过的确切版本；源记录变化、撤回或过期后退出。近期自述不会直接变为采用人格，也不会自动建立任务。

上下文总量和区域限制可用`contextBudget`配置，阶段人格用`growthMaxBytes`配置。必带材料先占预算；不足时报告容量问题，不能静默丢弃。诊断区分序列化字节、保守token估算及模型实际公布的限制。自动检索有固定页面、候选数及时间边界，查询不写入长期选择。

旧工具结果只有在已观察、效果已知且能按来源重新取得时才缩短为回执和分页引用；最近8份结果保持正文，调用与结果配对保留。未知效果不因压缩而重试。

本版Memory存储升级至13，只新增近期状态及其修订/发布记录。升级须在Host空闲并停止后，通过现有Host计划迁移、备份、应用和核对流程进行；保留安装身份、旧记录及已有删除状态，不重新初始化。关闭新功能不删除记录。升级后不能用旧二进制直接读新结构，也不能以旧备份覆盖新产生的真实记忆。

本版验收以本地程序与组件检查为发布前置，真实模型语义、平台表现及日常交互由部署者另行验收。
