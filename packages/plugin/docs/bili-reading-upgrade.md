# 0.25.1 B站阅读升级

本版完成搜索、批量画面阅读、阶段工具范围及长任务接续。无需启用子代理。

## 阅读流程

搜索直接接受关键词。HTTP 因已登记的诊断状态暂停时，已配置浏览器的实例可以使用浏览器读取搜索及视频资料；账号或页面身份不符时停止。评论续读返回短游标，去重集合留在后端。字幕翻页复用已取得的字幕文件。

`bili_frames` 一批最多取 6 帧，记录请求位置、实际位置及逐点失败。把成功帧的 `source` 一起传给 `dafeiyu_media_read({mode:"images",sources:[...]})`，进行一次视觉请求。相同资料的新请求可命中任务内缓存；部分失败不作为完整缓存。可用画面不代表已经处理音轨或看完整段视频。

B站阅读任务只暴露阅读工具及必要的任务控制工具，执行入口再次核对范围。普通开发任务保持原有宿主工具。是否进入阅读阶段根据任务目的与授权资源决定，不根据“安装了B站插件”推断。

## 长任务

阅读记录按任务及任务版本隔离。上下文只携带最近的短记录、未结束条目和总进度，最多约 4 KB；完整记录与原始回执保存在数据库。`bili_reading_get` 可按需分页读取详情。

每完成 3 个不同视频的记录，或下一次请求达到上下文预算时，在发送模型请求前切段。默认输入软限 24,000、硬限 32,000 token，按模型实际窗口及输出预留进一步收紧。采用请求计量器的估计值，不以字符数除以固定常数代替计量。

切段将检查点、前段结束、子段创建、任务期限和证据引用作为一个事务提交。新段建立新的模型会话，继承同一任务总截止时间。单次任务最多 8 段；到期、无可压缩的超大首请求或达到段数上限会明确失败并保留进度。用户取消优先于内部接续。只有最终段进入结果交付。

累计 token 消耗仍会增长，这是完成工作产生的总消耗；每次请求携带的上下文受预算限制。失败或重启时使用持久状态恢复，存在未确认写入效果的任务不会自动重做。

## 升级

本版 B站数据库为 **v5**，运行数据库为 **v2**。支持 B站 v2/v3/v4 和运行库 v1 的显式升级；不在构造器中偷偷升级。

1. 停止实例并确认没有运行中的任务，备份实例数据和 DSH profile。
2. 运行新包的 `node bin/dafeiyu.mjs check --settings <配置文件>`。
3. 运行 `node bin/dafeiyu.mjs migrate --settings <配置文件>`。迁移器核对身份、结构与占用，分别生成一致性 SQLite 备份；重复执行只报告当前版本。
4. 对齐 profile 的包声明、依赖锁和实际插件链接，重新初始化生成的配置并启动。
5. 用 `status` 核对实际运行版本、启动状态及插件状态。发布包的 `release.json` 记录版本、源码修订、内容摘要及存储版本。

源码附带 `source/scripts/repair-dsh-profile.mjs`。默认检查 BOM、锁文件及链接；修复步骤见 [配置文档](configuration.md)。不要使用会加入 BOM 的旧版 PowerShell UTF8 写法生成 JSON。

降级须在实例停止后同时恢复旧包、profile 和迁移前数据库，不能只把插件链接切回旧版本。升级保留既有平台诊断暂停，不自动解除账号或接口限制。

离线验收使用真实 Host、DSH 执行循环和存储，外部模型、浏览器与平台响应采用固定测试数据。它可以验证程序调用链和恢复行为；真实账号登录、平台页面及模型表现需另行验证。
