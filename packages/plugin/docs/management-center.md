# 大肥鱼管理中心

DSH 设置中的管理中心只接受已认证的主人连接。页面通过共享管理协议调用实例，不把管理操作暴露为模型工具。

## 生命周期

自动启动、按钮、重启和重试共用一个控制器。启动中重复请求复用当前操作；运行中启动正常返回当前 PID；停止优先取消正在启动或等待依赖的流程。

页面显示阶段、操作 ID、PID、代次、当前错误及有界历史错误。操作期间持续刷新，可见页面稳定后降低频率，离开页面停止轮询。过期响应不覆盖新状态，刷新不清空配置草稿。

启动中、运行中和停止中禁用启动按钮。后端独立保证重复请求安全。已有进程尚未确认就绪时，通过本实例 IPC 核对，不创建第二个实例。

停止清理本管理器拥有的进程、QQ 服务、桥接及计时器；复用的外部 OneBot 不归本管理器关闭。旧进程迟到消息不能改变已停止或新一代实例。

配置、Node 或数据迁移错误给出具体原因，不以无意义重试掩盖。正常就绪后清除当前错误，历史记录仍可查看。

## 配置与模块

配置保存和实际运行分开。先保存，再按字段要求重启；账号、凭据路径和身份相关变更在停止后应用。模块草稿一次保存，同时检查字段所有权与配置修订。

人格与记忆、能力、任务、运行和提示词预览使用各模块的真实接口。任务未知效果不因重复操作而重新执行；动态上下文预览不调用模型或执行上下文准备。

任务详情分别展示业务结果和结果交付。生成或核验阶段中断且原材料仍有效时，可使用“继续生成或核验结果”；按钮按交付版本提交，不重跑原业务。受理不等于送达，核验中断会复用原候选。过期、取消、来源失效、已确认或未知发送不借此重试，详情保留阻止原因与最近恢复错误。

## B站验证

“验证登录”和“测试读取”返回操作 ID，由后台执行。连续点击复用当前操作；取消保留中断记录，重启不重放旧验证。状态查询只读，不请求平台。

页面分别显示凭据格式、账号验证、读取接口和暂停范围。Cookie 原文及内部指纹不返回 UI，见 [B站登录与读取](bilibili.md)。

主实例状态与组件状态分别呈现。QQ 在线且实例接受任务时，B站接口受限显示为组件限制，不会把整个实例改为启动失败。

## 自主活动与媒体恢复

自主活动页显示模型暂停、探测回执及旧探索的待处理原因。“验证模型恢复一次”先返回探测记录，页面轮询实际结果。一次探测不运行任务工具、不向 QQ 发消息；401/402/403 不定时反复探测，瞬时故障在退避后最多自动探测三次。同一路由在故障之后开始的普通请求成功，也可确认恢复；旧请求迟到成功不能解除新暂停。

媒体页的“允许下一次读取验证”只授予该故障范围一次短期许可，不代表组件已恢复。已有等待探索在空闲、授权仍有效时沿原任务补读；实际受影响阶段成功后才解除暂停。新的配置、成功下载或缓存命中不能替代视觉/音频处理的成功证据。

恢复继续尊重主人任务、安静时间和明确休息；无需等下一次新候选发现周期。每条探索最多自动接续三次。取消、检查点失效、未知外部效果或次数用尽会保留明确原因，主人可检查后另行交办；管理入口不清除这些保护。

主动文字分享会让出主人交互。尚未外发或只有已确认片段、且剩余部分确定未发时，保持待发送状态；下次空闲重新核对来源和批准正文后续发。来源或已创建交付凭据过期时停止，不能为了补发绕过校验；回执未知的片段也不自动重试。
