# 验证范围

验收按当前源码和实际生成包分别执行，不累加旧版本或重复复测的测试数量。

| 层次 | 内容 | 能证明什么 |
|---|---|---|
| 类型与程序回归 | 生命周期、协议、存储、登录缓存、诊断、读取、来源和交付 | 固定输入及故障条件下的程序行为 |
| 独立发布包 | 自有依赖安装、CLI 检查、空数据初始化、身份稳定、启动及重启 | 不依赖开发工作区完成安装 |
| DSH 装配 | 实际 profile 解析、管理调用、冷启动、重复启动及进程清理 | 当前包在被验收 DSH 中运行 |
| 真实平台 | 真实账号、模型、QQ/B站及媒体后端的明确样本 | 该时间和环境下实际通过的能力 |

完整回归使用 npm test；短冒烟使用 npm run test:smoke。独立安装与模型/平台样本另行运行并保存可复核记录。慢盘或隔离目录可设置 DAFEIYU_TEST_CONCURRENCY=1 串行运行，以排除多个 SQLite/SDK 测试争用；不放宽每项功能的取消和超时边界。

B站真实验收先登录 UID，再视频、搜索、评论和字幕样本。平台仍受限时保留错误与暂停，不宣称风控解除。网页可见、字幕可读、画面采样、视觉理解及音轨处理分别记录覆盖范围。

安装检查必须核对实际依赖与加载目录；静态 ready 不等于在线。最终报告记录当前测试运行 ID、版本/修订、库版本、备份、进程就绪回执和未完成的外部条件。历史报告不会作为本版重新执行的证明。
