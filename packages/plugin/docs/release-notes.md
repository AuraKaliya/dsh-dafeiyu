# 0.27.0

- 持久化原始请求、补充、确认、继续与进度查询的关联和回执，防止重复建任务、重复修订或把“可以”当作新目标。
- 统一百万上下文容量，去除旧阅读、检查点和最终整理的总数量/字节门槛。工具历史按 SDK 的实际投影计量，估算偏高不提前拒绝输入。
- B站字幕批量续读返回准确 next 参数；评论使用短游标；视频分 P 标识由程序解析；媒体整文件读取兼容已验证的完整 Range 协议。
- 实际媒体理解回执能进入工作进度，并在最终交付时保留有效的来源能力。资源暂停不牵连无关 API；登录有效与接口成功继续分开判断。
- DSH 目录可查询、参数可读取、阅读阶段的白名单工具可实际执行。宿主在派发前拒绝不属于只读范围的动作。
- 修复临时模型连接失败和不合法 JSON 参数导致的任务中断；修正当前请求时不重放已完成的工具。
- 来源索引按新增记录维护，撤回记录增量读取，媒体 JSON 只在入口校验一次；权限、撤回和内容哈希检查保留。
- 修复列表形式的操作回执阻断最终汇报，以及最终交付阶段来源临时租约丢失的问题。

当前扩展协议为 API 6，运行库为 v3，B站库为 v6。新装直接初始化当前结构；旧实例停机备份后执行 migrate，逐表核对原内容。回退必须同时恢复匹配的程序、配置和数据库。

安装步骤见[安装指南](install.md)，测试范围见[验证范围](validation.md)。历史版本说明保留在 Git 与历史文档中，不作为当前安装步骤。
