# 0.26.1

- 管理生命周期统一启动、停止、重启和重试；修复重复重启、停止后的迟到就绪事件、启动错误丢失及等待依赖时的清理。
- Cookie 登录校验按账号与凭据代次缓存，同一检查合并并发请求。修复过期/不可读凭据仍显示已验证、全部等待者取消不结束请求、途中换凭据仍可能消费旧结果。
- 管理验证采用有界、绑定身份与接口的许可；匿名历史不阻断新账号校验，账号或共享限制保持生效；登录成功不清除其它接口的风险。
- 请求保留全局有效冷却，接口暂停按实际目标匹配。资源请求不携带 Cookie，匿名签名读取仍取得必要的 WBI 材料。
- 移除已弃用的搜索来源枚举工具、重复 OneBot 启动检查和仅供旧调用方使用的诊断接口。必要的数据迁移保留在显式迁移器。
- 显式 init 可补建新增模块的存储并保留身份；丢失的既有必需库不会被重建为空库，占用释放也会等待协调事务。
- 统一首次安装、配置、管理与B站说明；部署目录独立安装依赖，预检分别报告静态就绪与在线状态。

新安装直接创建 B站 v6、运行库 v2。已有实例先停止、备份并运行 migrate。详见 [安装指南](install.md) 与 [验证范围](validation.md)。

更早版本的开发记录在源码仓库历史文档及 Git 中保留，不作为当前部署步骤发布。
