# 0.28.0

- 主人私聊可查询当前获准群的目录和消息，群之间继续隔离；任务状态支持按范围分页查询。
- 修复分段回复被新消息打断后，恢复工具参数结构导致下一轮尚未调用模型就失败的问题。
- 增加持久群巡视计划：检查增量缓存，使用实际收到的消息参与本群讨论；无新消息不调用模型，可选择保持沉默。
- 自由探索先检查新候选、既有阅读状态和持久休息/暂停，避免每分钟重复启动同一材料；新发现可经现有结果核验及QQ账本分享给主人。
- 媒体连接等待、正文停滞和总传输期限分开，持续下载不会再被普通API的15秒期限截断；增加阶段诊断、资源暂停、实际读取缓存和部分帧成功的覆盖记录。
- 请求用量分别记录非缓存输入、缓存读取、缓存写入和输出，标明未知及历史未细分数据。保持百万上下文容量，不新增任务总token限制。
- 当前 API 7，runtime v4，activity v3，media v3，B站 v6，QQ v8。新装直接初始化；旧实例必须停机备份后显式迁移并核对原数据。回退同时恢复匹配的程序、配置和数据库。

真实平台与连续运行的通过范围以对应验收报告为准，构建成功不等于平台验收通过。
