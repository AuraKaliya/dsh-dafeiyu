# 0.28.3

- 本机主人委托复用QQ消息序列契约，执行器无需查源码猜测多条消息的交付格式。DSH目录支持跨名称和描述的多词查询，避免词序不同误报未找到。

- 对已验证受理的任务，异常工具控制文本不会发到QQ；保存原始模型记录，并交付准确的受理通知。
- 媒体阅读进度复用未变化的本地事实，每次仍检查外部来源权限；本地删除、外部数据库更新都会使复用失效。

- 当前消息的任务实际受理后，前台回合进入简短确认阶段，不再继续执行或轮询后台任务。判断来自已持久操作和实际子任务，普通状态查询或伪造的accepted字段不能触发；下一条消息可正常继续、修订或查询。
- 高频消息来源校验按trace和事件类型读取，复用既有索引；缓存只保存事件事实，不缓存权限判断。本地追加、外部提交和事务回滚会使相应缓存失效。消息仍逐次读取当前行，仅复用完全相同的正文解析结果。
- DSH普通文件结果按页预算直接展开正文；大子节点明确标记未读并提供续读入口。列出字段和路径不再被标成读完正文；保留完整结果、任务边界和数字精度。
- 当前存储版本不变，仍使用现有显式迁移和独立发布包安装流程。最终验收以本轮记录为准。

# 0.28.2

- 模型依赖恢复后，失败探索沿原任务和检查点有界续办，保留已读证据、任务权限及已确认操作。旧回调不能覆盖新故障；账户类错误等待同一路由的新成功或主人验证，瞬时故障最多自动探测三次。
- 媒体批量读图与其它读取共用分范围暂停。修复组件后可允许一次实际读取验证；只在受影响阶段真实成功后解除暂停，缓存命中不会伪装成依赖恢复。
- 恢复后的成果可以沿原分享路径送达主人。未知写入、取消任务、失效来源和超过三次接续的记录保留待处理原因；不会为了续办清除回执或重建整项任务。
- 主人正在交互时，主动分享先排队，不提前生成表达。文字分享被新消息打断时保留已批准正文和逐条回执，空闲后仅续发确定未发的部分；未知回执不重试。未创建交付记录的排队分享从实际受理开始计算有效期，冷却按实际送达核对。
- B站读取通道暂停后，按范围收窄下一步的可用工具，并保留本地阅读记录和状态入口。临时不可用不被解释成未安装，也不改变旧证据的授权；依赖恢复后的接续重新装配工具。
- JSON 只读请求遇到连接重置等短暂网络错误，在已记录的短退避后最多内部重试一次，避免把一次连接抖动变成多轮模型调用。登录失效、风控、验证码和管理中心的一次验证许可不套用此重试。
- 管理中心新增模型探测和媒体验证入口。探测在用量账本中按恢复/维护单列，没有对应业务 Run 的健康请求仍如实显示。
- 活动库、媒体库显式迁移至 v4，runtime 保持 v5、B站 v6、QQ v8；当前安装说明已同步。

真实平台与连续运行的结论以本轮验收报告为准。

本版为本地验收候选，是否通过真实对话与连续运行，以对应验收记录为准。

# 0.28.0

- 主人私聊可查询当前获准群的目录和消息，群之间继续隔离；任务状态支持按范围分页查询。
- 群查询明确区分本轮回复目标与平台发送权限，保留实际收到的 @ 信息；缺少提及元数据的旧记录保持未知。
- 修复分段回复被新消息打断后，恢复工具参数结构导致下一轮尚未调用模型就失败的问题。
- 增加持久群巡视计划：检查增量缓存，使用实际收到的消息参与本群讨论；无新消息不调用模型，可选择保持沉默。
- 自由探索先检查新候选、既有阅读状态和持久休息/暂停，避免每分钟重复启动同一材料；新发现可经现有结果核验及QQ账本分享给主人。
- 媒体连接等待、正文停滞和总传输期限分开，持续下载不会再被普通API的15秒期限截断；增加阶段诊断、资源暂停、实际读取缓存和部分帧成功的覆盖记录。
- 请求用量分别记录非缓存输入、缓存读取、缓存写入和输出，标明未知及历史未细分数据。保持百万上下文容量，不新增任务总token限制。
- 当前 API 7，runtime v4，activity v3，media v3，B站 v6，QQ v8。新装直接初始化；旧实例必须停机备份后显式迁移并核对原数据。回退同时恢复匹配的程序、配置和数据库。

真实平台与连续运行的通过范围以对应验收报告为准，构建成功不等于平台验收通过。
