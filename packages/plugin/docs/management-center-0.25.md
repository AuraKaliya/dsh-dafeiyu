# 大肥鱼管理中心 0.25.0 开发记录

本轮只修改本项目。当前自有模块统一为 0.25.0，公共协议为 API_VERSION 5。没有数据迁移、协议别名或多版本读取器。记忆库和活动库采用当前 schema 2。

## DSH 设置入口

客户端通过官方 `settings.section` 插槽注册“大肥鱼管理中心”，复用 DSH 的 React 和认证 Remote。使用工作区中的六个横向页签：总览、人格与记忆、能力、任务与记录、提示词预览、运行。

管理服务留在宿主进程，Agent 使用独立子进程。配置缺失、启动失败或停止时仍能打开管理页。仅 DSH 已认证的 owner 连接可以调用管理入口，请求正文不能声明管理身份。配置文件仍是唯一配置源，多个模块的草稿一次校验、按 revision 保存；不会同时维护另一套 DSH 配置副本。

模块自己的 `src/management-definition.ts` 提供分类、字段、单位、说明、提示词来源和面板名称。记忆、QQ 表情、任务和活动的详情界面分别在模块的 `client/management.js` 中注册。中心组合这些描述与组件，Host 通过模块方法访问业务数据，不查询其它模块的私有表。

## 具体行为

- QQ：连接组件、唯一饲养员、七项消息收发设置分开。连通检查查询实际登录账号和组件版本，不发测试消息；更换绑定前必须停止实例。自然延迟按 Unicode 字符数计算，最少值、每字增量、上限和分段间隔均可设置。同群背景与主动历史回看分开限量。表情支持搜索、原件预览、编辑资料、停用、软删除和恢复；保留原件仍计入容量。
- 人格与记忆：读取已保存的底色、自我认识及明确反思；管理普通记忆和反思依据的删除、恢复。删除反思依据使相关自我认识退出可用视图，恢复依据不改写原有文本。没有直接覆盖人格的编辑器。
- B站：保留公开内容、字幕、弹幕读取、媒体观察及唯一主人私信管理；增加请求节奏、时限和大小设置。修复安装配置中 B站声明多嵌套一层的问题。不增加发表评论、发布弹幕等能力。
- 多媒体：区分文件限制、缓存、视觉、视频、ASR、声音事件、文档和语音合成；提供实际引擎路径、模型校验、版本及内存配置。可移除可选引擎配置。渠道的媒体发送许可仍归 QQ 管理。
- 任务：读取执行状态、回执、已核验结果、明确反思、用量和检查点。暂停、取消、继续走原执行引擎，检查版本、授权及未知效果，不直接修改运行状态。
- 运行：查看实例、版本与真实模块状态，管理启动、停止、重启和模型引用。凭据只显示引用路径，不读出文件内容。

## 自主活动

程序先检查前台排队、运行、待发送回复和 QQ 合并队列，再等待配置的持续空闲时间。允许的工作分为已有计划、记忆整理和空闲探索；能力范围进入实际执行策略。空闲探索通过同一个 DSH 任务循环，由 Agent 选择一次活动或休息，不构造 QQ 消息来源。

单轮默认 10 万 Token、15 分钟。有效触发先执行一次，活动完成后幂等累计实际用量与用时，再判断下一项。达到或超过任一预算结束本轮，不因轮次预算中断当前活动。轮次间隔从上一轮结束计算；前台抢占和主人暂停保留轮次与累计用量。单次任务故障时限、取消与授权失效仍单独生效。

主模型、同进程辅助模型和受信执行子进程分别记录实际用量。DSH 的未缓存输入、缓存输入相加一次，推理 Token 不重复加入输出。缺失用量标注待核实，停止本轮续行。运行中单独保存预算时对下一轮生效；其他配置下次启动生效。

## 提示词与缓存

预览使用当前源码固定字面量、当前输出契约和记忆中的初始底色；动态正文统一显示 `【动态提示词】`。按模块标色并提供管理跳转，不执行 prepare、模型或工具，不显示会话原文和内部推理。独立视觉请求标明其参与条件，不声称它属于主会话。

底色仍来自首次保存的记忆。运行时保留通过来源校验的历史快照，新状态追加完整快照；最后一份快照才代表当前状态。空快照明确表示当前没有材料。来源撤回、权限失效、到期或无法核验时撤出相关材料。模块没有历史核验能力的材料不会为了缓存被无条件保留。压缩与最终请求容量检查继续生效。

这提供可复用的稳定前缀，不代表已经测得供应商的缓存命中率；预览也不冒充最终传输的 Token 顺序。

## 当前边界与验证

SnowLuma 的程序安装、升级、许可和账号登录仍由原组件负责；管理中心管理 OneBot 连接、身份和实际状态，不内置另一套组件安装器。系统执行页面查看已装配执行器的环境与授权状态；独立安装方式缺少宿主授权及共享计量端口时明确显示未装配。DSH 文件、浏览器和插件能力使用宿主当前公开目录及原有授权，管理页不会通过开关制造系统权限。补充任务的新指令仍应从原任务的已认证来源进入。

本轮验证包括基础单元测试、原有三项本机短装配检查、原生客户端注册检查、界面浏览与本地发布目录生成。没有恢复长流程测试，没有调用真实模型或外发 QQ/B站消息，没有连接服务器、部署、发布或关机。真实 DSH 宿主挂载与真实平台交互尚未验收。

开发预览：`node scripts/preview-management.mjs 63579`。预览复用实际界面组件，只含明确标识的示例配置；运行按钮不会操作真实实例。

最终检查：npm run check 的 214 项通过；npm run test:smoke 的 3 项通过。基础测试实际执行约 3.8 秒，短装配约 0.6 秒；构建和类型检查另计。
